P018 · pip 装新包报 "No matching distribution found"：本机默认走清华镜像，新包未同步

现象

装小众/刚发布的 Python 包时，pip 直接报“找不到版本”，看起来像包不存在：

Looking in indexes: https://pypi.tuna.tsinghua.edu.cn/simple
ERROR: Could not find a version that satisfies the requirement skillopt (from versions: none)
ERROR: No matching distribution found for skillopt
第几次 结果 直接原因
1（2026-09-16 anydoc） 清华源找不到 firecrawl-anydoc 镜像未同步
2（2026-09-16 skillopt） 清华源找不到 skillopt（PyPI 上 v0.2.0 已发布） 同上，同一天同一坑

根因

本机 pip 默认 index 是清华镜像（pypi.tuna.tsinghua.edu.cn），镜像对冷门/新发布包有同步延迟甚至长期不收录。

  • 直接原因：镜像 index 里没有该包的任何版本 → (from versions: none)。
  • 根本原因：把“镜像里没有”误读成“PyPI 上没有”。二者的处置完全不同 —— 前者换源即可，后者才会去看项目是否改名/未发布/需要源码安装。
  • 判定要点：Looking in indexes: 那行就是证据，报“No matching distribution”时先看它。

解法

换官方源重装（包已在 venv 里，换源不影响其它已装依赖）：

pip install --index-url https://pypi.org/simple <pkg>
# 或 -i https://pypi.org/simple

官方源直连耗时参考：本次 30 个依赖约 2m05s，可接受；不要用长超时去死等清华源“过会儿就好了”。

预防规则（判断是否上浮 L1）

可抽象成铁律，但 L1 当前 4407 字符已超硬上限 4000，暂不新增块，留在本库：
