现象

做小说漫剧国风版，连续调用宿主 ImageGen 全部返回 429（连发 1 张也限流）， 等待 60–105 秒后仍 429 —— 短时间大量生成（图+视频混跑）会触发配额级限流，恢复窗口不明。

备援通道：Agnes AI（本机已有 skill + key）

~/.agents/skills/agnes-image-video/agnes_cli.py，key 在 ~/.zshrc 的 AGNES_API_KEY （非登录 shell 不导出，需 export AGNES_API_KEY=$(grep -m1 AGNES_API_KEY ~/.zshrc | cut -d= -f2 | tr -d '"'"'"' ')）。

四个实操点（都实测过）：

  1. 输出 CDN 免 auth：data[0].url 指向 platform-outputs.agnes-ai.space， 直接 GET 即可 200 下载；带 Authorization 头反而 401（CLI 的 download 子命令是给视频用的，别照抄）。
  2. 尺寸不听话：请求 size=1536x1024，实际返回 1248×832（3:2）—— 下游 pipeline 按 1248×832 设计裁剪（如 16:9 去水印：crop=1248:702:0:65），别写死请求值。
  3. RPM 6/分钟：批量生成脚本里 sleep 12 sequential 跑；超频返回 429/503， 503 是上游临时过载，退避 20s 重试即可（skill 文档已载）。
  4. 出图风格：agnes-image-2.1-flash 对「国风插画/水墨写意」响应极好 （实测优于日系动漫 prompt 的表现），现代都市+国潮题材可直接用； prompt 里加「无品牌标识」避免生成美团/饿了么等真实标识。

教训

  1. 多模态生成要有备援通道意识：宿主工具限流时，本机 skill 库里的其他 API 通道 （Agnes）可以直接接上，管线不用改（都是出 PNG）。
  2. 接新通道先看三件事：响应结构、下载是否要 auth、实际输出尺寸 —— 这三个和文档承诺的都不一样。
