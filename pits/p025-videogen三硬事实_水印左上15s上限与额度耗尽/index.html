三个硬事实（2026-10-15 实测）

  1. 水印在左上角：「AI生成」约 200×45px，位于 x≈8,y≈6。 与 ImageGen 的右下角完全不同——按 ImageGen 经验裁底部会漏掉。 输出是 1764×1176（3:2）：裁 crop=1764:992:0:92 一步同时完成 「去左上水印 + 转 16:9」（上裁 92 / 下裁 92）。
  2. 单段最长 15 秒：seconds=16 直接报错 seconds must be between 3 and 15 （schema 注释里的 “4-30” 不适用于当前模型）。长面板要么接受 15s + 冻结补帧， 要么拆段。
  3. 额度计费，耗尽即 429：错误体 {"code":14018,"msg":"额度已用尽，请访问以下链接， 购买加量包以获取更多额度"} —— 与普通限流（等一会就好）不同，是硬配额， 买加量包前一支视频都出不来。5 秒 ≈ 50-100 credits，13-15 秒 ≈ 130-300。 大批量动画化前先问额度余量，或先发 1 段试水。

处置记录

《我能闻到所有人的秘密》漫剧 E01 3D 真人版：8 镜全动画化开工， p1/p2/p4 三支成功（15s/13s/9s）后额度耗尽，p3/p5-p8 五支未出 → 先出「3 动画 + 5 静帧」混合版交付，余额度后补完剩余 5 支。

教训

  1. 图生视频和文生图的水印位置、输出尺寸都不一样，接新通道必须逐项量 （角区裁剪抽帧 + ffprobe），不能沿用旧通道经验。
  2. 额度型 API 的 429 要读错误体：14018 额度已用尽 是购买入口， 普通 RPM 限流是等待——处置动作完全相反。
  3. 混合版（能动的先动 + 静帧运镜兜底）是额度中断时的合理交付形态， 比干等或全静帧都好；剩余镜头补额度后增量生成即可（管线不变）。
