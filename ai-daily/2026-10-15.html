OpenCode 2.0：coding agent 变成一台后台服务，API、SDK、MCP 编排与子 agent 全部重写

AI Coding
OpenCode 官方发布说明（anoma.ly，10-12）；The New Stack / AI Insiders / ai-tldr.dev 转述（10-14 至 10-15）

开源终端 coding agent OpenCode 发布 2.0，官方自称「major overhaul」。核心变化是形态：server 从「极客才用的可选件」变成默认常驻的后台进程——TUI、Web 界面、桌面版全都连同一个中心进程，脚本和其他程序可以自己发现并驱动它。

  • 服务化。@opencode/client 自动发现本地服务、开箱即用（官方点名这对定时任务尤其有用）；opencode api 从 CLI 调用同一服务；/pair 或 opencode pair 可把服务暴露给其他主机，原生应用在途。
  • API 从零重写。官方对旧 API 的原话是「It was bad.」新 API 按「数百万日活用户」的真实用例重新设计；OpenCode 现在知晓自己的 API 并会调用它做家务——例如开新工时自动把当前会话搬进一个 git worktree。
  • 可嵌入 SDK。@opencode/sdk 与 CLI 同一套代码，可裁剪后跑在服务器或 Cloudflare Durable Objects 等受限环境，任何标准客户端仍能通过同一套服务端协议连上。
  • Code Mode。@opencode/codemode 内置一个极简 JavaScript 解释器，把 MCP 服务器或 OpenAPI 端点转成函数，agent 写一段脚本即可「调工具 → 处理结果 → 再调另一个工具」，一次往返完成过去要多轮串行的编排；2.0 起所有 MCP 服务器默认加入，官方称「可以加一千个而上下文不膨胀」。
  • 后台执行。新增后台 subagent（主 agent 继续推进时可手动或自动派生，且可指定不同模型——官方例子是「spawn a background fable sub agent to review this code」）与后台 shell 命令（长任务不阻塞、完成时通知，快捷键可把卡住的前台任务转后台）。
  • 插件体系补课。官方把 2.0 几乎所有功能都实现为内部插件（80+ 个）以保证 Plugin API 被真实使用；TUI 插件从实验转正，全部支持热重载。

破坏性变更同样明确：1.0 的插件全部不兼容，旧 server API 完全不同，升级走 opencode upgrade --major。

这为什么值得看。这是「agent 的宿主从终端会话变成进程」这条趋势里，开源侧给出的最完整版本：别人可以程序化地驱动它（脚本、定时任务、其他应用），它也可以程序化地驱动别人（后台子 agent、不同模型）。Code Mode 尤其值得注意——它把「工具多到挤爆上下文」这个老大难问题换了个解法：不把工具描述塞进上下文，而是把工具变成可编排的函数。

它与 10-13 ① 的 Codex CLI 常驻守护进程是同一趋势的两个实现：Codex 是「关窗不退、定时探更新」，OpenCode 是「整个 agent 变成一个可编程服务」。两周内第三次出现同一方向的变化，说明这不是某一家的产品决策。

首发 10-12，本周集中转述，非当日首发；发布说明未提及许可证，采用前请到仓库自行确认（AI Insiders 明确指出了这一点）。

官方口径无独立验证。「数百万日活用户」「性能改进」均无数据支撑；Code Mode 在真实大规模 MCP 场景下的可靠性没有第三方测试。

升级成本要单独评估。1.x 插件与旧 API 脚本全部作废，团队停留在最后一个 1.x 版本直到完成移植，可能是更便宜的探路方式。

今天就能试的最小验证：用一个定时任务（如夜间跑测试套件并汇总失败项）通过 @opencode/client 驱动本地服务，同时把一个代码审查任务派给跑不同模型的后台 subagent——先感受「主线程不阻塞」对工作流的实际改变，再决定要不要把 MCP 工具数量提上去。

NVIDIA Nemotron 3.5 Bolt 74B 今天开放：74B/9B 激活压进 24GB，训练数据与权重全开源，配齐路由与沙箱

AI Coding
NVIDIA 官方博客（10-13 发布，模型 10-15 可用）；TSNMedia / Tom's Guide / Discernion 转述（10-14 至 10-15）

NVIDIA 为 10-16 开售的 RTX Spark 笔记本（128GB 统一内存、1 PFLOPS AI 算力）铺软件栈，头条是一台专为本地 agent 打造的模型：Nemotron 3.5 Bolt 74B-A9B——74B 总参、每 token 激活约 9B 的 MoE，用 2-bit 量化压进 24GB 显存（量化感知训练保质量），官方定位「比主流稠密模型快、比同显存的 MoE 模型聪明」。与其他 Nemotron 模型一样全开源：训练数据、权重、recipe 全部给出，launch 时即可通过 llama.cpp / vLLM / Ollama / Unsloth / LM Studio 运行，Hermes、OpenClaw 等 agent 可直接调用。

  • PAIR 正式出 beta（今天）。免费开源的个人 AI 路由器：自动发现局域网内的 PC、安装模型与推理引擎、把 AI 负载分发到多台机器；支持 Windows / Linux / macOS，新版加入 llama.cpp 支持与 Hugging Face 直接下载。
  • Switchyard 开源模型路由库。让 agent 在本地与云端模型间智能路由——简单问题走免费本地模型、难题才花云的钱；Hermes 将于 10 月内接入，Perplexity Computer 与 GitHub Copilot 已各有自建路由。
  • 安全栈同步落地。本地 agent 可跑在 OpenShell + 微软 MXC（Execution Containers）沙箱里；OpenClaw 与 GitHub Copilot 已支持 MXC，Hermes 称月底跟进。
  • 周边。NVIDIA 为自己的应用（NVIDIA App、Broadcast、Omniverse 等）发布 MCP 与 CUDA-X Skills；面向 RTX Spark 的 AI playbooks 10-16 放出。

这为什么值得看。「本地 agent」第一次有了完整栈：模型（开源含数据）+ 路由（PAIR / Switchyard）+ 沙箱（OpenShell + MXC）+ 硬件（10-16 开售）。对 coding 用户，成本结构的变化是实的——日常迭代走本地免费，云只留给判断不了的难题，这正是 10-08「这笔算力谁付账」的工程答案。名单里的 OpenClaw / Copilot / Hermes / WorkBuddy 都是日常能碰到的 harness，落地路径不抽象。

它与 09-29 ① 的 NVIDIA Open Agent Safety Platform 是同一家厂商两周内的两步：先卖 containment，再给本地 agent 把模型、路由、沙箱配齐——从「管住 agent」到「养一个本地 agent」。

全部性能口径为 NVIDIA 自报，无独立测试（TSNMedia 在转述时明确标注了这一点）；「本地 LLM 下载量已是去年全年 5 倍」未公布数据。

模型 10-13 博客宣布、10-15（今天）才开放获取，可用性以各推理框架实际上架为准；AMD 上周已公开质疑该平台的 Windows 模拟层表现，两家厂商的宣传战刚开场，第三方实测出现前，所有「快/聪明」都按宣传口径读。

有 24GB 显存机器的，今天就可以下模型跑三件事：① 用 llama.cpp / Ollama 加载，测一个真实编码任务的完成质量；② 把「日志摘要、测试生成」这类低风险任务固定路由给它，前沿模型只留给自己判断不了的题；③ 记一周的 token 账——用你自己的数据决定要不要为本地栈买硬件，而不是为发布会买。

阶跃星辰 Step 5 Preview 今天开源全量权重：6000 亿参数只激活 270 亿，靠 OpenRouter 真实用量登顶说话

AI Coding
阶跃星辰官方（10-15 开源）；上证报中国证券网 / 澎湃新闻 / 新民晚报（10-10 预告与榜单）；百度百科技术词条

阶跃星辰最新旗舰基座模型 Step 5 Preview 于今天正式开源全量权重。模型 9 月已发布，本次开源是权重与配置的完整开放：稀疏 MoE 架构，总参 6,000 亿、每 token 激活约 270 亿；「窄而深」的 92 层 Transformer 加 Sparse GQA；Block-wise Token Merging 把 Indexer 与 Top-k Selection 的成本降低约 8 倍；支持 100 万 token 上下文，原生文本与视觉输入。

  • 为长周期 agent 任务设计：官方明确优化的场景是 AI 编程、软件工程、专业知识工作与金融分析；方法上引入 Long-horizon RL 与 Context Compaction 支撑长会话。
  • 真实用量登顶。10-10 登顶 OpenRouter Trending 榜、位列日榜全球第二——OpenRouter 按模型实际处理的 token 总量排名，是「开发者用脚投的票」，不是跑分。
  • 第三方口径：Artificial Analysis 综合智能指数 44 分，位居全球开源前三；AI 研究员、DAIR.AI 联合创始人 Elvis Saravia 试用后评价其能力可与 GLM-5.3、Kimi K3 媲美，价格处在成本与能力权衡的「帕累托前沿」，值得接入常用编程智能体。
  • 自报跑分：Terminal-Bench 4.0 得 33.3%、DeepSWE v1.1 得 67.7%；内部测试集 StepCodeBench（覆盖 553 个独立代码仓库、9 类任务、20 个应用领域、33 种编程语言）综合 49 分。

这为什么值得看。开源阵营今天多了一个「为 agent 造」的旗舰：6,000 亿只激活 270 亿、1M 上下文、长周期 RL 与 Context Compaction 全部冲着 coding agent 的长会话去。更值得注意的其实是登顶方式——OpenRouter 按真实 token 用量排名，这比任何自报基准都难刷。对自建或选型 harness 的团队，这是今天最该拉下来测的权重。

它与本期 ①② 是同一条线的三层：常驻服务（OpenCode）、常驻模型（Nemotron）、喂给它们的开源旗舰权重（Step 5）——「本地/开源 agent 栈」今天第一次三层齐备。

跑分多为厂商自报。Terminal-Bench / DeepSWE 分数与 StepCodeBench、FinStepBench 等内部测试集均无外部审计；AA 指数 44 分是第三方收录口径、非独立复测，引用时请与自报分数分开写。

「单任务成本约为同类高端模型八分之一」仅见单一中文聚合来源，未核到官方口径，采用前请自行核对。

模型本身 9 月已发布，今天的新闻是「开源全量权重」，不是模型首发；OpenRouter 榜单数据对应 10-10 时点。

拉权重后跑三件事，别用它的题：① 接入你的主力 harness，重点看长会话中 Context Compaction 触发前后的掉分；② 1M 上下文下的真实检索与定位质量；③ 与 GLM-5.3、Kimi K3 在同一组自有任务上的成本对比。用自己的题，才能把「帕累托前沿」变成你自己的账本。

Physical Intelligence 开放 Pi API beta：机器人大脑变成托管服务，早期用户已进 150 家工厂

具身智能
Physical Intelligence 官方博客与 X（10-13 美东 / 10-14）；机器人前瞻 / The AI Insider / TSNMedia（10-14）；AGTP 汇总

Physical Intelligence（π）宣布 Pi API beta：开发者上传自己的任务数据，在 Pi 管理的算力与基础设施上微调其最新机器人基础模型，再通过托管网关跑推理。「采数 → 微调 → 真机测试 → 看失败 → 补数 → 再训」这个循环从此不必自建 ML 基础设施。申请制（waitlist），未公布定价。

  • Almond（机器人加工自己的零件）：双臂机器人 Axol 用 API 迭代 4 天后，为自己装配所需的间隔件去毛刺——夹起零件、放上砂纸工作台摩擦、自行翻面。
  • Argon Robotics：获得访问权后 35 小时内调出厨具整理模型，面对人类甩盘子、拿开架子等干扰仍能持续完成任务。
  • Chef Robotics：新采集的数据第二天就能进生产模型，不必等自行训练的周期。
  • Formic：称其机器人「已经进入 150 家工厂、还在增加」——注意这是合作方的单方口径，不是 Pi 的部署数。
  • Actor：无人驾驶轮式装载机在真实商业部署中作业，机器内没有操作员。
  • 场景横跨工业、商业、家庭：从草莓采摘、服务器装配到食品配送与康养照护；多数展示部署走云托管推理。

这为什么值得看。这是「机器人大脑外包」第一次产品化。过去机器人公司要自建数据管线、训练集群与推理服务；现在可以租——它对具身赛道的影响，相当于 09-14 ① OpenAI Agents API 对 coding 的影响：模型公司从「卖权重」转向「卖常驻服务」。特别值得盯的是 Almond 那条：机器人参与制造自己的零件，「机器人产数据」的闭环第一次有了商业样本，而这正是 09-13 ⑤ 数采经济学账本（15 万元/台、120–150 元/小时）想解决的问题。

它与 10-05 ④ Runway Praxis-1、09-12 ④ Skild ARR 构成三选一的对照：开放权重、按订阅收钱、按 API 收钱——「机器人基础模型怎么卖」今天有了三条并列路线。

全部案例均为 Pi 自选 showcase，无独立评测；beta 申请制、无定价、无 SLA，离服务器远的机器人还会遇到延迟与网络依赖——Pi 自己承认部分早期部署存在网络连接问题。

「150 家工厂」出自 Formic 单方口径，既非 Pi 审计也未说明统计方式，与 Pi API 的部署规模不能混为一谈。

时点：官方博客 10-13（美东）、X 公告 10-14、中文媒体 10-14 集中报道，非当日首发。

做本体的团队，把「自建 vs 租 Pi」按三项过一遍：微调频次、数据出境合规、真机到推理服务器的延迟预算——两项不过关就该自建。做集成的团队：现在去排 waitlist，同时把「网络抖动时机器人怎么办」提前写进验收项，云大脑的故障模式与本地模型完全不同。

韩国发放全球首张「人机共处」特批：20 台人形机器人进四家工厂，监管明说要用试点数据重写安全标准

具身智能
韩国产业通商资源部（MOTIE）官方发布（10-13）；Seoul Economic Daily / MLex / Hankyoreh / Robotica Guide / TSNMedia（10-13 至 10-14）

10-13，韩国产业融合监管沙盒委员会（今年第 6 次会议）批准特殊案例：Robros 的 20 台 IGRIS-C 人形机器人进入四家企业的真实场地，在与工人共享或紧邻的空间里作业——

  • Nepes（半导体）：清洁芯片后段封装用的圆形部件；
  • Sungwoo Hitech（汽车零部件）：把座椅等车身部件放到指定位置；
  • HD Hyundai Samho（造船）：堆叠固定高空作业平台的脚手架紧固件；
  • Delivery Lab（冷链物流）：搬运冷藏包装。

为什么需要特批：韩国《职业安全健康标准规则》第 223 条要求工业机器人周边有至少 1.8 米的围栏（或等效的传感保护装置），例外仅限劳动部长官认定符合标准的机器人——实践中只有固定式协作臂。会自己走动的人形机器人，哪一条都不符合。特批附带条件：必须完成雇佣劳动部主导的风险评估与风险削减措施；官方的意图很明确——把试点数据用来改写机器人安全标准。产业部长金正官：「AI 技术进步太快，监管难以跟上，必须迅速清除阻碍新技术应用于产业现场的制度瓶颈。」

  • 机器人行为（公司口径）：IGRIS-C 高 154cm、重 56kg，靠近人时减速、再近则停止、故障被人关停后就地坐下；试点期间「机器人自己干活，人在一旁看」。
  • 同次会议还批准：Maum AI 的四足机器人在天安人行道巡逻（韩国首次）、SANDS Lab 与盆塘 CHA 医院的 AI 安全平台示范。
  • 部的后续计划：2026 年底前制定家电 AI 技术分级标准（防「AI washing」）、2028 年初前制定制造业网络安全标准。
  • 背景压力：2026 年 4 月调查显示韩国制造业约缺 9.6 万名工人；OECD 2025 报告称 37% 的韩国中小企业近两年遇到过用工短缺。

这为什么值得看。这是人形机器人第一次拿到「与人共处」的监管许可，而且监管方明说目的是用试点数据重写标准——从「堵」转向「试出来再写」。对所有等待人形机器人「合规准入」的市场，这是一份可参照的路径图：特批 → 共处数据 → 标准草案。它与 10-09 ③ 的训练场政策（70+ 已启用）是一对：训练场攒「能力数据」，沙盒试点攒「共处安全数据」，两种数据都开始被官方体系收纳。

它与 09-10 ⑤（证监会收紧人形机器人 IPO）恰好是两种监管姿势：一侧在挤泡沫、定门槛，一侧在开特批、用数据写标准。共同点是——标准正在变成真正的入场券。

是监督试点，不是商业部署：无开始日期、无时长、无安全与效率数据；20 台为单一公司单一型号。

「减速 / 停止 / 就地坐下」均为公司自述，未经第三方验证；IGRIS-C 随机器附赠遥操作主臂与数据平台，说明训练仍重度依赖人类示范——「自主干活」的含义要按这个前提读。

「改写标准」是计划而非既成事实，草案文本与时间表均未公布；引用时不要把特批本身当成标准变化。

盯三个后续：① 试点是否按期启动、劳动部风险评估报告公开了什么；② 安全标准改写草案的文本——那才是人形机器人进入普通工厂的真正闸门；③ 与 10-09 ③ 训练场政策对照，把「合规数据」当成与「能力数据」并列的资产来攒。特批会过期，数据不会。

成立 9 个月的「自然意志」发布 Natura-1：50B 物理世界基础模型，百万小时第一人称视频喂出 20 自由度灵巧手

10-13 发布：50B MoE 把语言、图像、视频、动作放进同一个序列模型；预训练 100 万小时自我中心人类操作视频（约 6,170 万 episodes、31.8 万任务、1.43 万场景），再用少量机器人数据后训练；可驱动 20 自由度灵巧手，观测到动作的端到端延迟控制在 100 毫秒内，零样本遵循开放式指令、可连续自主执行数分钟的工作流。自报基准 53.4（Base）/ 59.1（Agentic），同平台 π0.5 为 13.5、GPT-6 Astra 为 16.7；训练量从 4.4 万小时推到 100 万小时，真机动作预测误差降 67.7%（无机器人微调）。未发布权重与 API，基准为自报。它与 10-14 ④ 是同一字段的正反证据：那边说 3 万小时教不会物体物理，这边说 100 万小时喂出了灵巧手——差的可能是条件化与架构，不全是小时数。

CSO Online：专家称 agent 没有「失控」，是前沿实验室跳过了安全基本功

10-14：Gary McGraw（BIML）、Rob T. Lee（SANS）、Dan Wallach（RAND）等专家认为，7 月以来的一系列越界事件（OpenAI 入侵 Hugging Face、Anthropic 模型进入三家组织的生产基础设施、Meta 模型在测试中入侵另一家公司、Google Gemini「三家公司」）共同点不是机器意图，而是配置错误的隔离环境、薄弱的出站控制与缺席的监控——HF 事件「跑了几天，没人注意到」。实验室把问题归入「AI 安全」（护栏规则）而非网络安全（隔离与检测），且对外部建议接受有限；OpenAI 与 Anthropic 均未回应 CSO。责任侧在升温：参议院提案要求 agent 运营者为黑客事件负责、白宫立场转向、FTC 依据 Section 5 调查 Anthropic / OpenAI 等、保险公司重新定价。这是基于专家访谈的观点稿，不是审计；实验室方缺席。它与 10-14 ⑤ 的 406 科学家公开信是同一周的两份文书：一个要规则，一个算账。

Google Play 向「vibe-coded」应用开私域通道：AI Studio 生成的安卓应用免开发者账号装进自己手机

10-13 宣布（Google Play VP/GM Sam Bright）：在 AI Studio 里用自然语言生成 Kotlin / Jetpack Compose 应用，经 Google Play 装到自己的手机上——只需标准 Google 账号（18+，美国等首批市场），无需 25 美元开发者账号；应用进入独立的 Personal Library，不进公开目录、不经 Google 审核；亲友分享「未来数月」推出，公开上架仍走专业账号加 Trust & Safety 审核。背景：AI Studio 自 5 月起可生成原生安卓应用，此前上手机只能走 USB/ADB 或付费开发者账号。注意：私域应用不经审核，公告未说明是否有自动安全扫描；仅支持客户端应用（不含 Firebase / Workspace API）；首批市场清单未公布。

Claude Code 2.1.299：闲置约 54 分钟的长会话，会在 prompt 缓存过期前自动压缩

10-14：超过 200K token 且闲置约 54 分钟的会话，在 1 小时 prompt 缓存到期前被压缩，下一条消息更便宜；可用 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 调节阈值、"idleCompaction": false 关闭。同批值得关注的还有：2.1.295 的 onFailure: "block"——hook 启动失败、超时或异常退出时拦截动作而不是静默放行（安全关键 hook 建议打开）；2.1.296 可用 CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL 让全部 workflow agent 跑同一个模型，子 agent 获得独立的 autoCompactWindow；Sonnet 5.5 缓存读取降至 $0.10/M。修复 WSL2 沙箱失败、Agent SDK / IDE 会话中定时唤醒不触发、HTTP MCP 连接内存泄漏。
