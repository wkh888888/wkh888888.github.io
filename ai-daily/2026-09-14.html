OpenAI Agents API 开放公测：Codex 背后的「harness」第一次被拆成可租用的托管云服务

AI Coding · 基础设施
来源：OpenAI 官方公告《Introducing the Agents API》（9/10）· flowtivity.ai / devtoollab / genaidaily 技术解析（9/13）

9 月 10 日 OpenAI 将 Agents API 开放给全体开发者公测。核心一句话：你指定 task / model / tools / environment，OpenAI 替你跑那个驱动 Codex 的执行系统（harness）——会话持久化、上下文压缩、subagent 编排、崩溃自动恢复、工具按需加载，全由它管。

维度这次给了什么
开源底座API 由 开源的 Codex harness 驱动，开发者可翻阅协调模型调用、工具与上下文的核心逻辑，而非黑盒
三种环境none（纯工具调用，最便宜）/ openai_hosted（OpenAI 托管沙箱，跑脚本改文件）/ self_hosted（连自家 VPC，适合合规与 GPU 约束）
计费API 本身不额外收费，只按模型 token + 工具 + 容器（沙箱）计费；参考模型 gpt-6-astra
四个对象agent（模型+指令+工具+MCP）/ environment（代码在哪跑）/ session（跨任务持久）/ events（流式或 webhook 回传）

harness 里三件「每家都重写的 plumbing」被做成原语：① 上下文压缩（接近上限自动 compaction，任务可跨多个上下文窗口）；② tool search（按需加载工具定义而非全塞进 prompt，省 token 保缓存）；③ subagents（两行配置即可并行拆分、各自独立上下文、主 agent 汇总）。官方引客户数据：评测分 0.71→0.85、subagent 延迟降 4×、案例审查成本降 60%、失败响应降 86%。

为什么值得关注：这条把 09-12 那期反复出现的主线（能力在 harness 层产生，不在模型层）推到了产品化终点——OpenAI 的赌注很直白：「把语言模型变成可靠工人的那层，应该被租用，而不是每支团队重写一遍」。对国内做 Coding Agent 的团队，这意味着「自研 orchestration」的护城河被抽掉一层：要么认领 OpenAI 的托管 harness，要么去 fork 它的开源 Codex harness 自建。方向会朝「harness 即基础设施」收敛。
口径边界：① 客户数字（0.71→0.85、4×、60%、86%）均为厂商自述，非独立第三方基准。② 锁定风险是真实代价：编排层依赖 OpenAI 实现并随其模型版本迭代，跨模型厂商的 agent 平台更可能直接采用开源 Codex harness 而非托管 API。③ beta 期数据在美国处理，即便 self_hosted 也不支持零数据保留；国内合规场景需先评估。
可做的动作：① 长任务 agent 团队先用 none / self_hosted 模式接入，保留自有工具与 VPC，把「是否被 OpenAI 托管」当架构决策而非默认。② 把评估重点从「换更便宜的模型」转向「harness 的上下文压缩与缓存命中率」——这恰是今日第二条的题眼。③ 关注开源 Codex harness 仓库的公开演进，而非只看 API 文档。

InfoQ 实测：同一个模型，换不同编程工具，账单能差 70 倍——成本黑洞在「脚手架」不在模型

AI Coding · 成本账本
来源：InfoQ《同模型 token 差 70 倍》汇编（6 月独立测试 + Composio 八框架横评 + Artificial Analysis 编码智能体指数，9/13）

结论反直觉：AI 编程的成本差距主要来自模型外面那层「脚手架」，不是模型本身。把同一批基准换成完全不相关的模型重跑，工具间的排名几乎不变。

口子事实
启动税每轮对话都要重带系统提示词 + 工具 Schema：Aider 约 700 token，OpenClaw 约 2.6 万 token；跑满 15 轮，光脚手架就烧掉约 39 万输入 token。「每轮固定上下文 × 调用轮数」与总消耗拟合优度 R²=0.99
缓存命中新输入价约为缓存输入的 5 倍；Claude Code 输入 token 仅 1.5% 命中缓存，Codex 约 70%——结果 Codex 计费 token 多一倍，真实账单反而更便宜
贵≠好同模型跑 8 框架 / 30 企业工作流 / 240 次：单次成功成本从 PI Agent 的 0.028 美元到 Claude Code 的 0.195 美元，差近 7 倍；通过率从 OpenCode 的 46.7% 到 PI Agent 的 66.7%
MCP 叠加每多挂一个 MCP 服务器，每轮就多读一份工具说明书——工具越多，固定开销越大
为什么值得关注：它把「AI 编程贵不贵」从情绪问题变成了可核算问题，正好接住第一条（harness 决定成本）。选型该先看三件事：单轮固定携带多少 token、一个任务要跑多少轮、缓存命中率——这往往比换一个更便宜的模型更有效。整条线和 09-13 的「验收权外移·账本外移」是连续的：今天连「花了多少钱、花在哪一层」都被摊开了。
口径边界：① 「差 70 倍」是跨框架跨配置的总区间，不是同任务同配置下的对比，不能直接当某两个工具的倍数。② 三组测试口径不同，绝对值不可横向硬比；R²=0.99 说明的是「固定上下文×轮数」这一单一变量的解释力，不代表其他变量无关。③ 缓存命中率高度依赖具体工作流，别人的数字不遗传到你的仓库。
可做的动作：① 平台团队对账先查两项——单轮固定 token、缓存命中率，再看模型报价。② 挂 MCP 前先算「每轮工具说明书」的开销，按需懒加载而非全量挂载。③ 把「单次成功成本 / 通过率」双轴纳进工具选型，不只看标价。

WPS 表格 Agent 登顶 SpreadsheetBench V2：国产垂类 Agent 第一次在端到端榜单跑赢国际大厂

AI Coding · 垂类 Agent
来源：中国电子报 / 观察者网 / 三湘都市报（9/11–9/13）· SpreadsheetBench V2 Full 官方榜单

国际表格 AI 评测 SpreadsheetBench 更新 V2 Full 榜单，WPS 表格 Agent 以 50.86% 登顶并通过官方 Verified 验证；Claude Opus 4.6、GPT-5.2、Gemini 3.1 Pro 分别以 34.89% / 26.79% / 23.68% 列于其后。

这是 WPS 三个月内第三次登顶权威评测，恰好拼成三级能力验证：

时间榜单验证什么
6 月SpreadsheetBench V1 Full（73.46%，超人类专家基准线 71.33%）会做（需求理解 + 表格操作 + 公式交付）
7 月TableBench（72.54 分）会想（事实核验 / 数值推理 / 分析 / 可视化）
本次SpreadsheetBench V2（50.86%）做完（端到端业务工作流交付）

V2 把考题从局部操作推向端到端：321 项任务，平均每项涉及 11.8 个工作表、593.5 个单元格修改，「局部正确 ≠ 最终正确」。能力已进入产品：8/28 WPS AI NEXT「灵感应用」亮相，北京昌平区教育局骨干教师评审、北师大珠海校区实习管理已接入真实业务流程。

为什么值得关注：稀罕的不是 50.86%，而是它出现在端到端业务工作流榜——拼的不再是一次推理，而是对文件结构的理解、对软件能力的调用、对结果的自我校验。通用大模型在收敛，而垂类厂商手里的场景数据 + 工具链 + 交付闭环正变成短期难复制的壁垒。对打工人更直接：办公 Agent 的考核标准已从「生成得像」变成「交付得对」。
口径边界：① 50.86% 的绝对水平仍低，说明端到端复杂表格任务远未解决，「登顶」是相对当前所有参评模型的相对第一。② 榜单任务分布偏商业工作簿，「会做会想做完」三级用的是不同榜单，不是同一份试卷的纵向追踪。③ 产品落地（昌平教育局等）为具体场景接入，不等于通用办公全面替代。

生数 Motus2 世界模型：让机器人先「在心里推演动作后果」再动手，朝递归自我改进迈出第一步

具身智能 · 世界模型
来源：量子位《Shengshu's New World Model Enables Robots to Begin Self-Evolution》（9/13）· 生数科技发布

生数科技发布 Motus2 世界模型，核心是把机器人从「照指令执行」升级为「先预测动作后果、再自我评估」：形成 预测—执行—评估 的闭环，并朝 递归自我改进（RSI） 迈出初步一步，真实任务成功率明显提升。

关键定位：它把「世界模型」从视频生成延伸到机器人决策——模型不再只是生成一段看起来合理的画面，而是内部推演「如果我这么做，世界会变成什么样」，再决定要不要做。这与开源三维感知（今日速览 · 蚂蚁 LingBot-Map）是同一条逻辑：把「空间理解 + 动作预判」变成可复用的基础设施。

为什么值得关注：具身「大脑」侧补上了最关键的一环——机器人开始有「后果意识」。这正好对着 09-13 那期具身资本信用的核心矛盾（银河通用的「数采收入该不该打折」）：当真机遥操数据严重短缺、数采经济学被拷问时，世界模型代表的「用更少真机数据撬动更好泛化」的路线，是另一条能绕开「数据—收入」死结的可能。与 09-12 的 HuRo（用人类视频做 VLA 预训练）是同一困境的两种解法：一个靠数据量，一个靠模型内的推演。
口径边界：① 论文表述 RSI 是「初步一步」，并非已闭环的自我进化系统，宣传语里的「自我进化」要打折扣读。② 真实任务成功率「明显提升」未给统一基准数字，跨任务幅度不可直接比较。③ 仍是研究原型，离工厂 7×24 稳定运行还隔着可靠性与异常处理。

红杉领投 Mecka AI 近 5 亿美元：具身智能的瓶颈正从「硬件造不出」转向「数据喂不饱」

具身智能 · 数据瓶颈
来源：TechCrunch（9/11）· 国家数据局具身智能座谈会（9/10）· 36 氪 / 量子位相关报道

据 TechCrunch，机器人训练数据公司 Mecka AI 正以约 5 亿美元估值完成红杉资本领投的新一轮融资（3 个月前 Framework Ventures 领投 6000 万美元）。模式很直白：付普通人用身体传感器 + 手机录制日常动作（做咖啡、修车等），形成第一人称（egocentric）运动数据集卖给机器人公司与 AI 实验室；公司称预计 2026 年底达 1 亿美元年化收入。

赛道在升温：竞品 XDOF 传出接近 12 亿美元估值，Scale AI、Micro1 也向物理世界数据扩张。国内同步补规则：国家数据局 9/10 召开具身智能座谈会，表示将适时推动具身智能数据标准建设；触觉传感赛道 7 月以来至少 8 笔融资、合计超 25 亿元。

为什么值得关注：红杉买的不是机器人，而是把人类日常动作变成可训练数据的那条流水线——这等于公开给行业定了性：瓶颈正从「硬件造不出来」转向「数据喂不饱」。两个信号明确：① 数据来源的合规与稀缺性将成为核心竞争力；② 规则要开始定了——座谈会开在数据局而非工信部，意味着「谁采集、谁标价、数据怎么流通」即将有标准。这恰好是 09-13 银河通用「数采收入该不该打折」争议的上游解法：先把数据源头的合规与定价理清楚，下游 IPO 的「收入实质」拷问才有答案。
口径边界：① 估值与收入均为融资方 / 媒体口径，未独立审计。② 警惕「数据 = 新石油」叙事下的估值泡沫——外滩大会上清华许华哲已提出反方：百万小时数据不必然带来更好模型，按市价一小时数据数百元计、百万小时投入可达数亿元，应先确认「什么数据有效」再放量。③ 「数采收入该不该打折」的质疑（见 09-13⑤）在数据源头同样适用：数据公司的收入质量也需看客户独立性与复购实质。

蚂蚁 LingBot-Map 开源：普通摄像头实时重建 3D 空间，入选 ECCV Oral，GitHub 16.9K Star

蚂蚁「灵波」开源 LingBot-Map，用普通摄像头即可实时重建三维空间，论文入选 ECCV Oral，GitHub 已收 16.9K Star，开发者用于机器人导航与空间理解。这是灵波系列继 LingBot-VLA 2.0、LingBot-World 2.0 后的第三弹——开源三维感知工具正从研究原型走向工程可用，为具身智能的低成本空间建模提供新路径，与今日主榜④（Motus2 世界模型）同属「大脑/感知基础设施开源化」一条线。

特斯拉向 Optimus 核心供应链下约 5000 台批量订单：量产 S 曲线拐点，但灵巧手仍是最大瓶颈

据浙商证券研报与界面/证券时报，特斯拉 9/7 向 Optimus 核心供应商一次性下达约 5000 台批量订单，是今年 4 月量产指引以来首笔千台级；要求 9 月周产能拉到 1000 台、年底 2000–2500 台（年化约 10 万）、2027 年 50–100 万台，Gen-3 BOM 已压到约 2.8 万美元。但马斯克承认灵巧手是最大瓶颈（试产单台成本 4–5 万 vs 2 万目标，关节寿命约 1 年 vs 工业 5 年标准），量产节点已多次跳票。对照 09-13④ 小鹏 IRON「官宣量产但未披露产量」——特斯拉给出的是真实批量订单，但伴随明确的工程瓶颈。

麦肯锡 2026 AI 状态：32% 组织跳过采购改用 agentic coding 工具自建（科技界 41%）

麦肯锡年度报告显示，今年 32% 的组织跳过现成采购改用 agentic coding 工具自建，科技界比例更高达 41%。同期 YC 总裁 Garry Tan 称，借助 vibe coding 与 Agent 编程，今天一个人可能抵得上 9 个月前的 400 个自己，并建议把「一次成功的工作流」沉淀为可重复、可修复的技能文件。这与 09-13① 工信部「2 万家规上企业覆盖」目标互相印证：政策驱动与市场自发自建率，都在把「自己造 agent」变成常态。

OpenAI 同日暂停 $200 Pro 订阅：Astra 算力告急，与 Agents API 开放形成张力

9/10 起 OpenAI 暂停 200 美元/月的 ChatGPT Pro 档新订阅与升级（购买页置灰），Codex 产品负责人 Tibo 称 Astra 需求前所未有、暂停是维持广泛访问的最小措施，公司正加紧扩算力；同期用户晒出前后对比质疑 Astra 生成质量退化，OpenAI 回应模型上线以来未做任何改动、正在调查。这与今日主榜①（Agents API 开放）是同一天的正反两面：一边把 harness 开放给开发者，一边自家算力吃紧——基础设施开放的速度，卡在了底层算力供给上。
