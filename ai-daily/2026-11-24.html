同一组权重多走两遍，750B 模型自称有 2 到 3 万亿参数的智能：智谱把「深度」从堆参数改成循环计算，代码顺手外推到 3D 与仿真

AI Coding · 架构
智谱 GLM-5.4 发布（11-23 晚）· 澎湃新闻、华尔街见闻、界面新闻 11-23/24 报道 · 官方口径为主

11 月 23 日晚，智谱发布旗舰模型 GLM-5.4 并向 GLM Coding Plan 全量用户开放，同步上线 ZCode、Trae、WorkBuddy、Qoder 等编码平台。它是智谱首款 Loop Transformer 架构旗舰：在约 750B 基座里让 28 层共享权重循环推演两轮，不增加参数，靠「把同一组层多走一遍」换更深推理。

  • 官方给的数：同等参数对照下训练计算量增幅约 10%，平均输出长度下降 10% 到 14%，100 万 token 上下文；官方称智能水平可比 2 到 3 万亿参数模型。
  • 「泛 Coding」的定义被改了：不再只是写代码，而是把代码当成文本通往物理世界的接口，外推到视频生成、3D 建模与工程仿真，并新增视觉理解。
  • 开放节奏：先给编程套餐用户，API 在安全评估后开放，权重计划开源但要先做安全加固；不到 1% 的步骤不走推理，官方视作深度思考的特性。

为什么值得关注：这是「同一份本事换个走法」的最纯粹样本。过去两年旗舰的能力几乎都靠加大权重和显存买，边际成本随规模上升；循环架构反过来在同一组权重上多算几轮，把深度从参数维度挪到计算维度。它和端侧小模型的循环路线是同一个想法在两个极端上的验证。

「泛 Coding」把代码定义成驱动物理世界的通用接口，也正好接上 11-13 ④ 那场「编码智能体进物理世界」的考试：一个负责把接口造出来，一个负责验它到底能不能操作本体。

需要留意：2 到 3 万亿级智能、训练计算量增幅、输出长度降幅全部是智谱官方口径，权重开源和 API 时间待安全评估，未见第三方独立复现。不到 1% 步骤不走推理意味着时延偏长，官方把它讲成特性，时延敏感的场景得开发者自己验；「可比 2 到 3 万亿参数模型」是能力对标，不是参数相等。

可以怎么用：选型时别只看参数表，把「同一任务走几轮推理」也当成配置项来测：先用编程套餐跑一遍你自己的 agent 任务，记录时延与成本，再决定是否等 API 和开源权重。若做 3D 或仿真生成，现在就可以把代码当接口这条思路接进流水线试，但别在生产者里替代已验证的专用工具链。

2850 亿参数全程跑在 8192 张昇腾上从零训成：中国电信把权重当日开源、铺到 8 种芯片，可多数测试仍落后于同行的 Flash 版

AI Coding · 国产算力
中国电信星辰 AGI Lab 开源 Xing4.1-Preview（11-23）· arXiv 技术报告 11-17 提交 · 智源社区收录

11 月 23 日，中国电信人工智能科技旗下星辰 AGI Lab 发布并开源 Xing4.1-Preview（技术报告称「星河 4 号」），权重上 Hugging Face 与 ModelScope，采用 Apache 2.0 允许商用。

  • 架构：总参数 2850 亿、每 token 激活约 170 亿；45 层中 3 层稠密加 42 层 MoE，256 个路由专家每 token 选 8 个再加 1 个共享专家；注意力把多头潜在注意力与稀疏注意力组合，上下文 100 万 token（API 口径最多 89.6 万输入、12.8 万输出）。
  • 工程证明：预训练全程使用 8192 张华为昇腾 910C 加速卡与 MindSpore 框架，自研分片、优化器执行与内存管理稳住长跑；后训练用自建 TeleGym 平台跑 agent 任务、打分并回灌强化学习，架构围绕训练集群的算力画像从零协同设计。
  • 可用性：BF16 权重约 521GB，满精度约需 8 张 80GB 显卡；FlagOS 社区同步提供覆盖英伟达、昇腾、摩尔线程、海光、昆仑芯等 8 种芯片平台的 8bit 版本，支持 SGLang、vLLM 插件，天翼云开了兼容接口。

为什么值得关注：这不是又一个冲榜旗舰，而是一次「国产卡从零训出 285B、当日即多平台可用」的工程证明。在出口管制继续收紧远端算力访问的当口，可商用权重加 8 平台适配的部署价值，可能高于任何单项跑分——架构不是迁移后适配，而是围绕手里的算力画像重新设计。

但把它和 11-03 速览① 的 LongCat-2.5 放一起看更清楚：两款都是全程国产算力训出的大型开源模型，一个 1.6 万亿、一个 2850 亿；「能训出来」和「追平第一梯队」始终是两件事。

需要留意：在厂商自己的对比表里，它多数测试落后于腾讯 Hy4-flash、智谱 GLM-5.3-Flash 与 DeepSeek V4 Flash，仅在 Claw-Eval 领先 0.4 分；Terminal-Bench 跳过了 GPU 沙箱任务，HLE 只跑文本，对手分数又来自各自报告，口径并不一致，Artificial Analysis 也尚未评测。预览版意味着能训出来与追平第一梯队仍是两件事，选型前得用自己的 agent 任务跑一遍。

可以怎么用：如果团队有国产算力或信创部署要求，这条现在就值得拉权重试：先用 8bit 版本在自有平台跑通推理，再拿自家的真实任务集对照现用模型，别信厂商对比表的跨平台分数。521GB 的 BF16 门槛不低，单卡环境下优先看量化版的精度掉落幅度。

测试通过六成三，整单交付不到百分之八：SWE-CoWork 把 11 个模型放进模拟软件公司，证明「会写代码」和「把活干完」是两件事

AI Coding · 验收
TokenWave AI，arXiv 2611.20218（11-15 提交）· The Decoder 11-22 报道 · 中文圈 11-23 集中解读

新基准 SWE-CoWork 把编码 agent 当「数字员工」用：把 11 个模型放进模拟软件公司，101 个任务对应 101 个真实仓库，覆盖 11 种语言与 12 类应用。每个任务配 26 位职责各异、信息受限的模拟同事，约 82% 的需求只散落在同事嘴里；agent 从一段含糊的交接说明起步，8 小时窗口、17 个工具，从任务板、文档到聊天记录都得自己查。

  • 结果分裂：GPT-6 Astra 的 fail-to-pass 测试通过 62.91%，但整单完成只有 7.92%（8 个）；Claude Opus 5.5 是 63.84% 与 6.93%（7 个）；其余 9 款模型的整单完成率没有一个超过 0.99%。
  • 信息拿不齐：Opus 5.5 首轮提问 93% 找对了负责人，却只取回同事掌握需求的 64%；押后的问题常常没有下文；它自称完成的需求里 31% 没过对应测试。
  • 补规格没用：事先把全套需求直接给出去，测试分能涨约 16 个百分点，整单完成率却几乎不动——瓶颈不在信息缺失，而在收集、协调、实现、验证这条端到端交付链。

为什么值得关注：「测试通过不等于工作完成」从个例升级成了系统性结论。它和 11-21 ② 那 153 条失败笔记是同一个形状：那边是 agent 自报成功、退出码全绿，这边是测试六成三、整单不到百分之八——两处都在说自报状态与实际交付之间隔着一整条流程。

更关键的是「给全量需求也不涨完成率」这一条。它把责任从模型能力挪到了交付流程：补齐规格只解决「知道要做什么」，没解决「确认做对了」。这和 11-20 ③ 换裁判、11-17 ③ 把交接做成可打分流程是同一场仗的不同侧面。

需要留意：论文 11-15 提交、11-22 经 The Decoder 报道、11-23 才在中文圈集中解读，不是当日首发；8 小时窗口、26 位模拟同事都是设定，不等于真实公司的协作复杂度；与 11-17 提到的 Stripe Evals（均分 78.1%、全必过项仅 29.4%）是同构证据但不是同一套题，数字不可相减。

可以怎么用：把验收标准在开工前写成清单，最后对着清单由人复核，不要读 agent 的完工总结——这里有三成自报完成没过测试。任务边界划小、负责人写清楚，比换更强的模型更能救完成率；团队自建 agent 流程时，把「需求收齐」和「独立验证」做成两个不可跳过的关卡。

换一个仓库、换一批没见过的任务，成功率还保住九成：自变量把动作数据前置进预训练，10 小时产线数据就上手新分拣线

具身智能 · 零样本泛化
自变量机器人 WALL-OSS-1.0 发布（11-23）· 华尔街见闻、IT 之家 11-23 报道

11 月 23 日，自变量机器人发布新一代具身基础模型 WALL-OSS-1.0，并通过 WALL-API-1.0 向研究者与企业开放调用。它的关键改动是把操作数据提前到与文字、图像一同进入预训练，用自研动作分词器把连续动作编码成共享「动作语言」，同一段操作记录可同时用于学动作、理解动作、判断对错和纠错。

  • 成绩：厂商口径称在 312 个自选真机任务上零样本成功率 55.1%，另一项标准真机测试比专门微调过的 Pi-0.5 高 70.8%；仿真赛道位列单模型第一。
  • 产线：模型已进入国内一家头部物流企业的分拣产线，仅需约 10 小时产线数据即可上手，承担包裹翻转、条码对齐与异常件筛选；配套 XR Harness 负责长任务规划，换场地后仍保住约 90% 的速度与成功率。
  • 数据飞轮：训练数据含数十万小时、上千万条操作记录，其中占比最大的是操作员用手持 UMI 设备采集、无需机器人参与的数据；执行停滞或失败时由人接管，纠正记录回灌训练，已积累数万小时接管数据。

为什么值得关注：它把「零示范迁移」从论文指标往分拣线上推了一步：手持 UMI 绕开了机器人本体采集的数据瓶颈，失败接管则从损耗变成可训练资产，10 小时新产线数据也给出了一个可比的接入成本刻度。换场地还保住九成，正是「同一份本事换个地方还灵不灵」在物理世界的答卷。

和 11-16 ④ 的 PEAR 对照着看最清楚：那边证明零人类演示、零真机数据也能纯仿真练出泛化，这边证明把动作数据前置进预训练同样能跨任务；两条路线都在攻同一个「数据从哪来」的死结。和 11-11 ⑤ 的触觉路线则是数据模态上的分工。

需要留意：55.1% 与 +70.8% 均为厂商自报，312 个任务由厂商自选，测试集与对手设置未完整公开；「头部物流企业」未具名，10 小时上手也不等于达到产线节拍与合格率。此外 11-02 ② 曾报道自变量双臂分拣 1816 件每小时，那是 8 月直播里的单机效率口径，与这次的模型发布是同主体不同阶段，两组成绩不能混用。

可以怎么用：如果有关节型或轮式分拣线要换品类的场景，这条值得做小规模接入测试：用 10 小时量级的采数看能否达到现有节拍，重点盯异常件与换场地后的成功率衰减，别只看标准任务分数。手持 UMI 采集这条路对没有大量本体的团队尤其现实，可先建采集流程再谈模型。

同一天两笔超亿美元押注，赌的却是相反的不确定性：至简动力拿已验证的产线效率说话，另一家只押「在模型里练、到真机上验」

具身智能 · 资本路线
彭博社 11-23 报道 · 科创板日报、华尔街见闻 11-23 转述

11 月 23 日两笔大额种子轮同日落地，赌的却是完全不同的不确定性。

  • 至简动力（Simplexity Robotics）：成立仅一年零四个月，完成 1 亿美元 Pre-A 轮，蚂蚁集团领投，阿里、腾讯、红杉中国、蓝驰创投等老股东全部跟投，投后估值 16 亿美元。创始班底几乎完整沿袭理想汽车智驾核心架构。第二款人形机器人 iX 为轮式；首款 i7 Pro 今年 7 月已完成首批百台交付，进入工厂产线；与杭叉合作的超市前置仓分拣线 11 月初跑通，单机最高 450 件每小时、准确率 98% 以上；9 月底已开源多模态时序世界动作模型 SimpleWAM。
  • Embo：完成 1.1 亿美元种子轮，a16z 领投，Khosla Ventures、DST Global 与英伟达 NVentures 等参投，估值未披露。核心团队是 Dreamer 系列作者 Danijar Hafner 与 VideoGPT 作者 Wilson Yan，成员来自 DeepMind、Meta 超级智能实验室与英伟达 Cosmos，自称有跨 7 万张 GPU 的训练基础设施。路线是先用互联网视频与文本预训练世界模型，再接真机传感与电机，让 agent 在「想象」中用强化学习练动作和失败恢复。

为什么值得关注：资本已经开始为「已验证的交付」与「尚未验证的泛化」分别定价。至简把智驾量产工程平移到具身，手上有台数、工序和效率数字，要盯的是 450 件每小时能否长期稳定、客户是否复购；Embo 押「在模型里练、到真机上验」可随算力规模化，手里是研究与团队积淀，没有交付证据，要盯的是想象训练出的策略能否在陌生场景站住成功率和恢复率。

这比又一轮估值抬高更值得记录：同一天、同一赛道、同一量级的钱，买的是两种完全不同的风险。10-28 ④ 那批世界模型资本整合和 11-10 速览④ 的三组融资硬数字，都是这条线的上游注脚。

需要留意：两笔均为融资口径，至简的投后估值与 450 件每小时是公司与媒体报道数字，长期稳定性、客户复购未披露；Embo 没有产品时间表、客户或估值披露，7 万卡规模也是自称。世界模型「想象训练再真机验证」的路线在论文里成立，在产线上尚未有公开证据，不宜把融资额当作技术兑现的信号。

可以怎么用：看具身公司时把「交付账本」和「研究资产」分开记账：前者盯台数、节拍、合格率和复购，后者盯团队来历、训练基础设施和论文可复现性。若自家要做场景落地，优先找已有工序数字可核对的伙伴；若要押长期泛化能力，就用小样本真机测试去验对方的想象策略能不能站住。
