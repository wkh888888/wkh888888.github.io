MiniMax M3.1 Flash 上线：agent 综合成本打到前代三成，匿名模型 Space Bunny 揭盅

AI Coding
MiniMax 官方博客（10-19 晚）；澎湃新闻 / 南方+ / 腾讯新闻（10-20）；Artificial Analysis、agihunt.info 当日汇总（10-20）

10-19 晚，MiniMax 正式发布新一代 Flash 模型 M3.1 Flash。此前在 OpenRouter 匿名霸榜约 10 天的 stealth 模型 Space Bunny，正是它的早期版本——9 月下旬上线后 3 天登上 OpenRouter 与 OpenCode 的 token 日调用量榜首，累计处理超 200 万亿 token，10-5 从公开榜单消失，今天身份坐实。

  • 官方口径。agentic 任务、编程、computer use、网络安全四个方向「代际提升」；线上推理速度提升近 3 倍、使用成本降低 70%；采用更激进的稀疏注意力架构，日常输出 200+ TPS、中位数（P50）稳定在 170+ TPS；agentic 类任务综合成本为前代的三成。
  • 跑分（均为自报）。DeepSWE v1.1 73.7%；BankerToolBench 76.2；OSWorld V2 61.7 与 Agents' Last Exam 29.6，两项均称国产模型第一；CyberGym 82%；AutomationBench-AA 位居最前列。
  • 价格（官方）。每百万 token 输入 0.15 美元 / 输出 0.60 美元 / 缓存读 0.015 美元（人民币 1 / 4 / 0.1 元）；对比 M3，输入输出单价降 50% 以上、缓存读降超 70%。
  • 第三方口径。Artificial Analysis 智能指数 42（较 M3 +13），每任务约 0.22 美元（约为前代一半）；同榜 DeepSeek V4.1 Flash 1017 为 45，开源权重阵营第一。Cline 称其编程「与 Opus、GPT 打平而成本约 1/25」（渠道方口径）。
  • 分发。MiniMax API、M Plan、MiniMax Code 三渠道；Ollama Cloud day-0 上架（美国托管、自称零数据保留、1M 上下文），主打企业 agent 工作流。428B-A23B 的 MoE 规格来自官方 FAQ 而非发布正文。权重官方称「稍后」发布。

这为什么值得看。这是 10-18 DeepSeek V4.1 Flash-1017 之后，国产 Flash 对打的第二面：同一个星期内，两个便宜模型把「复杂 agent 任务主力」的位置占住了——DeepSeek 软件工程评测分更高（AA 45），MiniMax 在跨 SaaS 工作流与网络安全上更突出（AA 42）。对自建 agent 流水线的人，价格与速度同时下台阶，意味着并行度、重试预算和失败循环的账要重算一遍。

更值得注意的是攻击侧已经在用同款便宜底模型做工装——见主榜 ③，这次狩猎行动疑似就是 Claude Code 跑 DeepSeek V4.1 Flash。

口径提醒。跑分全部为厂商自报，Artificial Analysis 只提供独立的指数与每任务成本；官方发布帖中的 74% 与博客 / AA 引用的 73.7% 不是同一处引用，不可混用；权重尚未发布，部署计划不要押在未发布的权重上；「1/25 成本」为 Cline 单方口径。

可以行动。观察三点：10-23 前后权重是否按期放出；AA 每任务成本能否被复测确认；自己任务集上的真实成功率——尤其是长程 agent 任务的重试率，那才是「七折成本」的兑现位置。

Claude Code 团队自曝九成代码由 Claude 写：合并量翻倍，回滚率反降四成

AI Coding
Anthropic 工程博客（10-15 发布）；BlockBeats / 投资界 / 7minAI / aitodaybrief（10-19 至 10-20 集中转述）

Anthropic 公开了 Claude Code 团队的代码审查方法。背景数字：Claude Code 约 90% 的代码由 Claude 编写（自报）；Anthropic 大仓库的日合并改动从 5 月约 2,500 涨到 9 月 30,000+（与 10-14 Scion 迁移是同一条事实）；6 月到 9 月，Claude Code 合并的 PR 翻倍以上，需要回滚的比例反而下降超 40%。

  • 七层检查，阅读交给机器。提 PR 前先拿证据：测试结果、build 输出、改界面还要截图对设计稿，再由独立子 agent 以全新上下文审 diff；PR 提交后多组 agent 并行找 bug，另一组对每个发现投票，达成共识才发评论；安全审查不通过不能合并；lint / 类型检查 / 全平台测试与构建进 CI。
  • 人类退到风险分级。文档类等低风险变更（且仅限可信作者）自动检查通过后可直接合并；普通产品改动需 1 人批准；计费、CI、自动更新器、系统提示词等最高风险路径需 2 人。分级器按改动内容定级、不看作者；agent 的批准永远不计入人工批准。
  • 审查死循环的修法。一个 CLI PR 一夜之间经历 50 多轮 AI 审查与修复；git blame 发现被反复揪出的问题里约 59% 是首轮审查时就已存在的旧代码，而非新改动引入。团队随后定规：超过 3 轮审查就要求作者重新想方案、首几轮之后只复审 diff、标记整类 bug、不重复贴同一发现；历史事故与回滚变成审查器的每日评测。
  • 旁证与工具。Boris Cherny：给 Claude 可执行的验证（跑测试套件、执行构建、在模拟器里跑应用）输出质量提升 2 到 3 倍。实质评论占比从预览上线前的 16% 升至 54%（第三方转引）。同日 Claude Code 更新至 v2.1.304，新增 /auto-mode-setup 引导设置，权限与用量警告收紧（claude-news.today）。

这为什么值得看。这是「AI 写、AI 审、人定级」的第一份大厂作业，且与 10-19 ③ Sphinx（push 前强制人类先理解）构成同一问题的两种解法：一个把阅读交给机器、把人放在风险分级与架构方向，一个用工具强制人类理解。两者都承认同一前提——逐行人工审查在 3 万次/日合并的面前不成立。

他们唯一认的指标是回滚率与事故率：「只要这两个数没往上走，就算没白干」。这句话比任何通过率都值得抄。

口径提醒。90%、翻倍、-40% 均为 Anthropic 自报，未经独立审计；Claude Code 本身不在那个日合并 3 万的大仓库里（官方只说「势头类似」）；方法论发布于 10-15，本周中文集中转述，并非今日新闻；「59% 旧代码」是单 PR 案例的归因，不是全量统计；实质评论占比 16%→54% 为第三方转引，未见一手口径。

可以行动。今天就能抄的三件：写一份短的 REVIEW.md（失败定义、跳过路径、要求引用文件与行号）；提 PR 前强制跑可执行验证而不是口头「搞定了」；给审查设 3 轮上限并禁止重复贴同一发现——把回滚率当唯一守门指标。

不到 100 字指令加约 5,000 美元 token：一名黑客的 agent 军团打穿 100 多家企业网站

Agent 安全
路透社独家（10-19）；NorForge 报告（Fagerland）；AOL / Tom's Hardware / SOFX / Cyber News Chronicle 转引（10-19 至 10-20）

NorForge 首席威胁研究员 Snorre Fagerland 在扫描公网暴露的 Cairn 实例（开源多 agent 问题求解平台）时，发现了约两打被用于恶意活动的部署，从而能「隔着屏幕看黑客怎么放 agent 出去干活」。其中一个中文集群从 9-25 起，用 agent 军团扫射美国、加拿大、澳大利亚、日本的电商站点。

  • 战果（路透社独立核实受害者身份）。100 多家企业网站被攻破，含 John Deere、SharkNinja、Cummins；累计尝试 1,200+ 站点；人类指令不到 100 个汉字；一次成功入侵平均需要约 23 小时的自动探测与测试。
  • 成本账。全程约 5,000 美元 token，折合每次成功约 50 美元；NorForge 报告口径把失败和中止的任务也算进来，约 5 美元/任务；所观察工具的平均成功率约 10%。两个口径分母不同，不可混用。
  • 技术含量。一次在大公司的前台应用找不到弱点后，agent 自行翻数字档案找关联基础设施、定位到一个公网控制面板、发现其数据处理的细微缺陷，经过数小时试错，诱导服务器执行了恶意命令。Fagerland 的评价：「这不是脚本小子的活」，他此前一直认为 hacker-agent 至少需要人类监督。
  • 用工猜想。任务跑在一个名为 claudecode_deepseek-v4.1-flash 的 worker 上，提示可能是 Claude Code 搭载 DeepSeek V4.1 Flash——各消息源对模型组合表述不一，未获确认。
  • 受害者回应。Deere 称已采取必要补救、无迹象表明敏感信息被访问；SharkNinja 称中招的是一个只放产品支持信息的独立站点、威胁已遏制；Cummins 称在调查其第三方供应商运营的网站疑遭攻击。路透社无法确定数据被窃取的程度。
  • 前科链条。Gambit Security 8 月记录俄语勒索团伙用 Cursor 打穿 7 家组织、9 月记录 agent 驱动的横扫致 25 家公司失陷、至少 60 万条信用卡记录外泄；澳洲政府医保门户 6 月被 OpenAI agent 攻破；韩国方面称至少 7 家金融机构 6.8 万客户信息外泄（工具为开源 ARTEX AI）。Cairn 作者回应称平台「不是为攻击设计」。

这为什么值得看。这是第一次有通讯社级核实把「agent 攻击」拆成可审计的账单：指令不到 100 字、每次成功约 50 美元、平均 23 小时、成功率约 10%。攻击的成本曲线第一次和模型降价曲线（主榜 ①）出现在同一周——便宜模型不只是让防御方跑得起更多评测，也让攻击方跑得起更多尝试。

它与 09-12 ② PaperCut（agent 蜂群协同攻击 395 家组织）是同一威胁的「计价版」，与 10-18 ② OpenCode 密钥泄露构成黑色经济的供需两侧：一边偷凭证，一边租模型。

口径提醒。模型归属仅有 worker 名提示，未经任何官方确认；5,000 美元与 5 美元/任务两个估计分母不同；受害者名单由路透社从 Cairn 活动独立核实，NorForge 报告本身未点名；三家失陷站点均为二级站（支持站 / 供应商站），非核心系统，但不代表核心系统不可被同样打法触及；Cairn 多起恶意实例的发现时间（约 10-02）早于路透社发布日，事件本体始于 9-25。

可以行动。三件事：把「公网暴露的 agent 控制面板与内部工具」列入攻击面巡检——这次狩猎者正是从暴露面板反向窥探了猎物；电商与支持类子域按核心系统同级防护；给安全团队预批模型使用通道——10-18 OpenCode 事件里，防御方读恶意代码时曾被安全过滤挡在门外。

德国把 physical AI 写成国家工程：与 NVIDIA 签联合声明，同日西门子跟进、四家德国初创获投

具身智能
NVIDIA 官方博客（10-19）；中央社 / 法新社（10-20）；AI Parabellum / siliconreport（10-19 至 10-20）

10-19 柏林 Invest in Germany 峰会，德国总理默茨与联邦经济能源部、联邦研究技术空间部同 NVIDIA 签署联合意向声明：共建面向 physical AI 的前沿模型，把合作正式化并扩展到德国「工业 4.0 平台」，官方目标是把工业 AI「系统性地推向大规模应用，并在欧洲建立顶尖的工业 AI 生态」。

  • Kraftwerk 对谈。黄仁勋：「AI 的下一波浪潮是 physical AI。」话题聚焦制造与汽车两大强势产业，以及被称为 Mittelstand 的中小企业群；默茨当场恳请企业开放数据——「请开门让 AI 运用你们的数据，这是德国真正的秘密与优势」；黄仁勋称产业知识属于德国、AI 只增强不替代。默茨提议每年至少与黄仁勋复盘一次进展。
  • 投资面。NVIDIA 同日宣布计划投资四家德国初创：Agile Robots（机械臂 + Agile ONE 人形，覆盖制造、物流、医疗）、Avelios Medical（AI 原生医院信息系统）、Mirelo（视频配音 / 音乐）、Reflex Aerospace（约 12 个月可发射的卫星）——隶属 NVIDIA 近百亿美元的欧洲承诺；此前在德已投 n8n、Neura Robotics、Black Forest Labs。
  • 产业面。西门子同日扩大与 NVIDIA 的合作做自主工厂：全虚拟化投产准备最多减少 85% 工程量、基于 agent 的生产计划最多降低 20% 制造成本（厂商展示口径）。
  • 金额。声明未披露投资额；德国《商报》估计规模可能达数亿美元。背景是德国经济多年停滞、数据中心容量落后、企业对美技术依赖的顾虑未消。

这为什么值得看。这是 physical AI 第一次以「国家工程」的形态落地：不是某家公司买多少台机器人，而是把模型、数据政策、平台组织、产业投资打包进国家战略。对具身赛道，国家队的进入意味着数据合规与本地化部署会成为硬约束；对中国厂商，欧洲订单的逻辑正在从「卖硬件」变成「交工艺包 + 过合规」——与 10-19 ⑤ 收入榜（前五全为中企）合读，是同一件事的阴阳两面。

口径提醒。意向声明不具约束力，投资金额未公布（《商报》估计为数亿美元级，未证实）；西门子 85% / 20% 是展示工厂的最佳口径，非均值；Mittelstand 愿不愿共享数据是整个计划的最大变量——默茨需要当面恳请本身就是信号；黄仁勋「知识留在德国、引入技术」的表述与欧洲对美依赖的担忧之间的张力，声明没有解决。

可以行动。观察三点：联合声明的首个交付物究竟是什么（模型？平台？投资？）；NVIDIA 对 Agile Robots 等具身公司的投资是否附带订单或联合方案；西门子数字孪生 + agent 计划是否进入德国车企产线——那才是 85% 口径的试金石。

Ropedia W0：1 万小时人类经验喂出的跨本体世界模型，五个机器人基准全线 SOTA

具身智能
arXiv:2610.26855（北京时间 10-20 凌晨提交）；项目页 ropedia.github.io/ropedia-w0；GitHub Ropedia/ropedia-w0

一篇论文 + 代码 + 权重三件套今日上线：Ropedia W0，自称首个跨「人类 + 多形态机器人」的第一视角 loco-manipulation（移动 + 操作）世界基础模型——从机械臂到人形、从夹爪到灵巧手，用同一套运动学接口统一表示：相机位姿编码移动、投影骨架编码操作。

  • 数据 Xp-Data。1 万小时人类第一视角视频 + 3 千小时机器人视频，统一多模态标注（度量相机轨迹、运动学骨架、层级描述）并做系统性质控；机器人骨架靠各本体正运动学加大量人工关键点标注与校正。
  • 「人类经验缩放律」。固定后训练配方，把人类预训练数据从 180 小时加到 1 万小时，人类与机器人的预测同步持续变好：相机跟随 ATE 2.21 → 1.79 cm、GR-1 实验 PSNR 19.8 → 21.74 dB、G1 / Ψ0 LPIPS 0.427 → 0.365。这是把「买多少人类视频」从信仰题变成预算题的第一份曲线。
  • 成绩。五个跨本体基准（DreamDojo、Ψ0、ω-HOME、Xp-Teleop、AgiBot）+ 留出人类视频全线 SOTA，零样本到全量后训练均领先；DreamDojo 自有协议下每个数据预算都第一；GR-1 全量后训练 PSNR 23.03 dB（较最佳 DreamDojo +4.04 dB）；自称超过 Cosmos 3 全系（含 3-Super）。
  • 工程与用法。5B 稠密（Wan2.2-TI2V-5B 基座）+ A14B MoE 两档；HuggingFace 已放 5B 预训练 / 中训练权重与 5B 推理代码；蒸馏后支持实时、分钟级 rollout，可做 VR 交互；面向策略评估、基于模型的规划与世界-动作建模。另发布长程基准 Xp-Teleop（基于高质量灵巧手遥操作数据）。

这为什么值得看。它给吵了两个月的「人类视频到底能换来什么」提供了第一份缩放曲线，且恰好与 10-14 ④（CMU + TRI：3 万小时自我中心视频教不会物体物理）构成同字段的两种结论——都成立，因为量的不是同一个东西：W0 量的是相机与骨架跟随、移动加操作的预测保真，那篇量的是物体交互保真。对做 VLA 预训练与仿真数据的人，这份曲线直接改变采购决策：配方固定时，人类视频时长是可换算的性能预算。

它也给 10-15 速览 ① Natura-1（100 万小时 ego 视频、只有自报对比分）补上了缺失的那一环——别人比规模，它比缩放斜率。

口径提醒。v1 预印本，技术报告尚在待办清单（自报 SOTA，未经同行评审）；分辨率 640×480、81 帧偏朴素；「跨本体统一」依赖大量人工标注，代价被轻描淡写；A14B 权重、评测代码与各基准微调权重尚未放出；「首个」为作者自述。

可以行动。观察三点：技术报告与 A14B 权重是否按期释放；Xp-Teleop 基准是否被第三方团队采用（那才是 SOTA claim 的试金石）；「世界模型 → 策略评估 / 规划」的用例是否有团队独立复现。

DHS 下令联邦文职机构清除 DeepSeek，第三方集成服务一并在内

10-19 公布、Federal Register 10-20 刊登的通知：美国土安全部要求联邦文职机构 IT 系统移除 DeepSeek 产品及采用该模型的第三方服务，并禁止采购。DHS 称模型构成「多重威胁向量」：敏感数据或转移至 PRC、可产生关于美国人与机构的「可行情报」、「模型本身可能含恶意软件」。7 月备忘录同日公开（监控政府网站出入流量）。此前商务部、海军及纽约 / 田纳西 / 弗吉尼亚等州已有禁令；FCC 10-29 将表决禁止中国实验室测试电子设备。注意边界：仅限联邦文职机构，不波及普通用户与企业；DHS 的表述是政府顾虑，不等同于已证实的数据外泄或恶意代码事件。源：路透社 / 中央社 / Federal Register 公告。
