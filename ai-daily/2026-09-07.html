OpenAI 上线官方 Skills Catalog，大厂首次给 Agent Skills 定标准

GitHub Trending
openai/skills · 2026-09-07 登上 GitHub Trending · 25,607 stars

OpenAI 开源了 openai/skills —— 一套「Agent Skills」开放标准 + 技能目录，供 Codex 打包、分发、安装可复用能力。每个 skill 是一个文件夹：SKILL.md（名称/用途/执行流）+ 可选脚本与参考文件，Codex 把 skill 的名称和描述预加载进 system prompt，运行时自主选择是否调用。

目录分三层：.system（5 个随 Codex 自动安装，含 skill-creator / skill-installer / plugin-creator）、.curated（39 个，用 $skill-installer 按名安装，如 gh-fix-ci、gh-address-comments、playwright）、.experimental。安装位置支持全局 ~/.codex/skills/ 与项目级 .codex/skills/ 或 .agents/skills/。

官方 25.6k stars 社区 mattpocock/skills 240k stars curated 39 个
值得关注
  • OpenAI 等于官方承认：光有模型能力不够，最佳实践必须被编码成可复用格式 —— skills 从「社区玩法」升级成「平台一等公民」。
  • 但社区派 star 数是官方的近 10 倍，标准分裂风险实打实：官方目录与 Codex 强绑定，社区偏好平台无关格式。未来 3-6 个月是收敛期。
  • 对你的直接影响：你本地维护的 skill 跨 .agents / .claude / .codex / .workbuddy 等多宿主软链，若格式收敛就是一次批量迁移，值得提前盯住 Codex 这套目录结构。
  • 实操提醒：每个 skill 都吃上下文窗口，装太多会降低 agent 的选择准确率。skill 数量已经堆到几十个量级的，该做一次去重瘦身了。

微软 Project Zenith：Windows 11 变身「开箱即用的本地 AI 开发机」

9/4 发布
Windows Developer Blog 2026-09-04 · 首批 AMD Ryzen AI Halo（最高 128GB LPDDR5x）

微软 9 月 4 日发布 Project Zenith —— 不是新的 Windows 版本，而是面向高性能开发机的预配置 Windows 11 体验。硬件门槛：64GB+ 统一内存 + 250GB/s+ 内存带宽，官方说法是这套配置可以本地、不计量地跑 30B+ 参数模型。

预装链路：VS Code、GitHub Copilot、Windows Terminal、PowerToys、WinAppCLI、PowerShell 7、Git / GitHub CLI / Azure CLI、Python 3.14+、Node.js 24+、.NET 10、WSL 2 + Ubuntu。系统默认项也按开发者习惯改过 —— 资源管理器默认显示扩展名/隐藏文件/完整路径/详细信息窗格并开启长路径，关掉最近使用、同步提示、开始菜单推荐和账户通知。

Agent 安全侧：OS 级身份认证 + MXC（Microsoft Execution Containers）隔离容器，可声明式限制 agent 能访问的文件与网络资源，边界在运行时强制生效；配合 Agent 365 与 Defender / Entra / Intune / Purview 打通。

内存 ≥64GB 带宽 ≥250GB/s 本地模型 30B+ 首批平台 Ryzen AI Halo
值得关注
  • 微软给出了明确的 token 经济学分层：frontier 模型留给 frontier 问题，其余全部本地跑。这不是口号，是被写进 OS 默认配置的。
  • MXC 把「agent 能碰什么」变成运行时强制的声明式边界，而不是靠 prompt 自觉 —— 这是「把 coding agent 推上生产」目前缺的那一块，比又一个模型发布重要。
  • 代价也很直白：64GB 统一内存门槛意味着短期跟你手上的机器基本无关，现在只是「买新机才有的体验」，普及要等 OEM 铺货。

OpenClaw 2.0：AI 编程从「单人 Copilot」转向「团队共享 Agent」

v2026.8.1
上周末发布 · 933 贡献者 / 16,000+ 合并 PR（约占项目历史 PR 一半）

OpenClaw 发布 v2026.8.1，官方定性为「史上最大更新」。核心变化是共享云会话：agent session 不再随发起人的笔记本关机而消失，可以多人接入、交接、继续跑。归属模型分三层 —— 不可变的 Creator、可转让的 Owner、Participants 历史。

权限侧：基于角色的审批流、命令参数可限定到具体参数与工作目录、可校验脚本是否与审阅时签字的版本一致、越权需管理员批准。浏览器 UI 重建，把对话/文件/审批/配置/实时 agent 活动收进一个界面。安装器会自动探测机器上已有的 ChatGPT / Claude 订阅、API key、本地模型（Ollama / LM Studio）。

贡献者 933 合并 PR >16,000 周新增用户 450 万 单 agent 被攻陷 0.24 → 7 agent 0.86
值得关注
  • 竞争焦点变了：不再是「谁单点写码快」，而是谁能管理一次完整变更 —— 审批、交接、审计这套 scaffolding 才是企业采购单上的东西。
  • 那组概率数据值得抄下来：agent 数量 × 权限半径 = 风险乘数，1 个 agent 0.24，7 个就到 0.86。给自己搭多 agent 流水线时别只看吞吐。
  • 你本地装了 OpenClaw：2.0 的安装器会主动探测已有订阅和 key，升级前建议先备份 gateway 配置 —— 社区已反馈有迁移失败、gateway 损坏、认证报错的情况。

上半年出货 4 万台、融资 935 亿，但「超级时刻」的时间表严重分裂

产业数据
大湾区经济网 / 虎嗅 / 中财网 · 2026-09-07

2026 上半年国内人形机器人出货超 4 万台、占全球 97%；具身智能赛道融资 935 亿元、322 起，同比 5 倍，半年规模已超 2025 全年。同期宇树登陆科创板开盘暴涨 629%，市值一度 4449 亿元。但虎嗅的数据：上半年 22 家独角兽中，95% 没有持续正向现金流。

时间表分歧极大 —— 王兴兴：快则两三年、慢则五到十年；王鹤：当前基础模型约等于数字世界的 GPT-2，2028 年到 GPT-3.5/4 水平；特斯拉 Optimus 三代 7 月底量产，2026 目标 5-10 万台；优必选 2026 产能目标 1 万台。

上半年出货 4 万台（全球 97%） 融资 935 亿（+5×） 独角兽 22 家 / 95% 无正向现金流 工业场景占比仅约 9%
值得关注
  • 出货和融资都是上半年的存量数字，真正的分歧全在「什么时候能真干活」。数字漂亮不代表闭环跑通。
  • 王兴兴给了一个可验证的定义：把一台机器人带进任意陌生环境，能按语音/文字指令完成约 80% 的任务 —— 比「ChatGPT 时刻」这类比喻有用得多，可以直接当跟踪指标用。
  • 最扎眼的是场景结构：2025 年全球出货中，文娱商演 / 科研教育 / 数据采集 / 导览导购四类合计近 90%，工业制造仅约 9%。机器人大多「被生产出来」，还没「进厂打工」。

新华网：具身智能走向实用还要闯三关 —— 大脑不可靠、硬件拖后腿、量产难

官方口径
新华网 2026-09-07 · 央视《焦点访谈》2026-09-06 · 第二届世界人形机器人运动会

新华网 9 月 7 日发文：今年国内人形机器人累计交付约 1.5 万台、市场规模 20 余亿元，被业内称为「规模化应用元年」，但三道坎没过：「大脑」不可靠、硬件拖后腿、大规模生产难。

同期的第二届世界人形机器人运动会有硬成绩：北京人形机器人创新中心的「天工」在 100 米预赛跑出 9 秒 39（已破博尔特 9.58 的人类纪录），决赛提升到 8 秒 64。更关键的变化是 —— 去年多数参赛机器人靠遥控，今年大多实现了自主化，足球/网球/乒乓球这类需要实时预测轨迹的项目也有明显进步。

但央视和厂商自己的归因都很克制：成绩跃升不是某一项技术突破，而是算法、软件、硬件的全方位工程提升。焦点访谈的定调是「从技术展示转向价值创造」，工信部已启动实景实训专项行动，推动机器人进真实场景常态化应用。

累计交付 ≈1.5 万台 市场规模 20 余亿元 天工 100m 决赛 8.64s 今年参赛 多数已自主化
值得关注
  • 8.64 秒是真实进步，但官方与厂商都承认这属于工程化红利而非范式突破 —— 判断行业阶段时别把工程迭代误读成能力跃迁。
  • 「去年遥控 → 今年自主」这个对比，比跑分更能说明 VLA / 感知-控制链路的实际成熟度。
  • 政策口径已经切换：从「能不能做出来 / 能跑会跳」切到「能不能在真实工位连续稳定干活」。评价标准变了，后面看厂商宣传要换一把尺子。

顺带一提（今天没进主榜，但值得扫一眼）

  • Anthropic Fable 5.1 / Mythos 5.1（9/1） —— Terminal-Bench 4.0 55.8%、缓存读取降价 75%（$1→$0.25/M），Cognition 已把 Devin 部分流量从 Opus 5 迁过来。CodeRabbit 实测：45 项评审找出的缺陷数几乎没变（65→64），但生成评论从 253 条降到 166 条、琐碎意见 265→79，代价是单次耗时 +49%。不适合当所有 PR 的默认模型。
  • 吴恩达《AI Engineering Skills Map: Using coding agents》（9/6） —— 提出规划/执行/部署/监控四阶段，五项关键能力，并直指「超长自主运行的实际效用被夸大」。跟他上面 Fable 5.1 的实测数据互相印证。
  • GitHub HydraFusion（9/4 research preview） —— 多模型编排，在达到 Opus 5 基线的同时压低单次工作流成本。竞争从「你用哪个模型」转向「你怎么跨模型路由」。
  • 小鹏 IRON 融资超 9 亿美元、投后 63 亿美金（8 月），何小鹏亲任机器人业务 CEO，计划年底规模量产、2027 年月产能升至数千台。车企「造人」已成行业浪潮，共用供应链 + 自有工厂当训练场是他们的真实优势。
