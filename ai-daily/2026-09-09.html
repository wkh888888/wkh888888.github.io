Cognition（Devin）拿下 20 亿美元 E 轮，估值 480 亿美元：AI Coding 成为独立预算科目

AI Coding
来源：Cognition 官方博客 / TechCrunch / SiliconANGLE（2026-09-08）

a16z 与 Accel 领投，Founders Fund、General Catalyst、Avenir 跟投，NVIDIA、Benchmark、Lightspeed、Kleiner Perkins、Greylock、T. Rowe Price 等 30 余家参与。估值从 5 月的 260 亿跃至 480 亿美元（+85%），年化营收 run-rate 从 4.92 亿增至近 9 亿美元（4 个月 +83%）——营收增速与估值增速几乎同步，隐含倍数稳定在约 53x。

落地客户覆盖 NVIDIA（芯片设计）、GE Aerospace、Citi、Mercedes-Benz、Modal、Goldman Sachs。同期发布三个新产品方向：Devin Auto-Triage（生产事故首轮排查）、Devin Security Swarm（跨代码库漏洞猎捕）、Devin Automations（由 Slack / GitHub / Linear 事件直接触发，不须开一个聊天窗口）。官方定位是"独立 agent 实验室"——可自由组合最优模型（含自研 SWE 系列），不把客户绑死在单一模型厂商上。

反方与边界：① run-rate 是公司自报、未经审计的"上月×12"，不等于已实现营收；② TechCrunch 披露 2026 年预计烧钱约 8 亿美元，其中 NVIDIA 服务器集群年租达数亿——每 1 美元 run-rate 对应约 1 美元现金消耗；③ 历史争议：2024 年 Devin 首发演示被 Internet of Bugs 指夸大实际完成情况，2025 年 8 月裁员 30 人并向留任者提出"80 小时六天工作制"。
为什么值得关注：倍数没变、绝对值翻倍，说明这轮定价是跟着营收走的，不是纯情绪。真正的信号是资本认可了"独立 agent 层"这个生态位——在 OpenAI / Anthropic / Google 都在自卖 coding agent 的格局下，仍有企业愿意为"可换模型的中立层"付钱。对国内做 agent 的团队，这是"不绑模型"路线的一次估值背书。

Anthropic 发布《AI-Native SDLC Playbook》：瓶颈已从"写代码"移到"写规格"

AI Coding
来源：claude.com/blog/the-ai-native-sdlc-playbook · 作者 Louis Claxton（Anthropic Applied AI）· 原文 2026-08-21，本周在中文技术圈集中传播

核心判断很直白：agent 让 build 从数周压缩到数小时，但 plan / review / test / deploy 仍以人类速度运行，整体流程变成沙漏形。产出更多代码 ≠ 交付更多可靠软件，安全评审队列和变更委员会成了新卡点。

解法不是给每个阶段塞一个 AI 助手，而是把线性流水线改成闭环——每个阶段向版本控制提交一个产物，下一阶段从读取它开始：

intent.md（Plan）→ spec.md（Design）→ plan.md + diff + 测试（Build）→ 验证输出与 eval 结果（Test）→ PR + 评审发现（Deploy）→ 事件记录回写新的 intent.md（Maintain）。提交链本身就是审计追踪：谁提了需求、agent 产出了什么、谁批准的。

执行层分三层，且职责不可互换：

  • CLAUDE.md —— 项目级机构记忆，保持一页以内，同一个错误犯第二次就写进去。
  • Skills —— 建议性控制，让违规变少；任何必须无例外成立的策略，skill 背后必须有确定性机制。
  • Hooks —— 确定性控制（allow / ask / block），让违规几乎不可能；不可协商的 hook 放平台管理员持有的 managed settings，工程师关不掉。

几条最硬的规则：修 bug 必须先让 agent 写出会因预期原因失败的复现测试，提交后再修，同时用 hook 禁止其在修复期间编辑测试文件；生产监控的检测保持确定性（滚动窗口 + Western Electric 规则，模型完全不介入），只有突破后才按 sigma 分级调用模型；agent 可以做生产门之前的一切，但越不过它——分支保护把 agent 的一切变成 PR，发布 hook 阻塞到具名发布经理授权；并行会话 2–3 条起步，上限是"你能妥善评审多少条流"；evals 从近期真实任务收集 20–50 个，每个生产事件变成一条永久 eval。

边界：手册引 DORA 研究自认——AI 是放大器：平台、自动化测试、快速反馈都扎实的团队把速度转化为交付稳定性，基础弱的团队会放大既有混乱。它同时坦承 agent 目前是"生产力工具"而非"自主开发者"，离全自动开发还远。
为什么值得关注：这是前沿实验室第一次把内部 AI 原生研发流程系统化公开，类比 2016 年 Google 的 SRE 手册对运维的意义。对做 agent 工程的人，它给出了"记忆 / 技能 / Harness / 权重"各层自我进化的清晰坐标；对工程管理者，它把"AI 编码 ROI 怎么向董事会证明"从"感觉变快了"变成了可度量的 eval 与产物链。最反直觉的一条：代码生成越便宜，规划越重要——在 plan 阶段纠正一个错误方向，成本远低于在一份巨大 diff 里发现它。

OpenAI Astra 全面推送 Plus/Pro/Business/Enterprise；同批 agent 88 小时解 Navier-Stokes 千禧年难题

AI Coding / Agent
来源：OpenAI 官方（2026-09-08 21:06）、openai.com/index/navier-stokes-solution、Simon Willison 博客、TechCrunch

Astra 已全面推送给 Codex 与 ChatGPT Work 的 Plus / Pro / Business / Enterprise 用户，可直接上手（实机演示见 openai.com/gpt-tv/）。

同日更大的一条：OpenAI 宣布一组 agent 使用"能力显著强于 GPT-6 Astra 的下一代模型"，约 88 小时给出 Navier-Stokes 存在与光滑性问题的 blowup 解（证明初始光滑的流体可在有限时间内形成奇点，该问题悬置约 90 年），随后由 GPT-6 Astra 完成 17 小时 Lean 形式化验证。全程发送 490 万条消息、消耗约 3000 亿输出 token。

争议同步爆发：NYU 数学教授 Tristan Buckmaster 与 Anthropic 数学家 Levent Alpöge 称自己先有三项 blowup 结果，研究进展信息被泄露给 OpenAI，对方随后用大量算力沿其独特路线追赶；Sam Altman 回应称对方只有 Euler 结果、双方协调失败并遭抄袭指控威胁；Noam Brown 承认这次证明花费数百万美元，但认为成本会快速下降。

为什么值得关注：把它当agent 工程新闻读，不是数学新闻。真正的看点是"大规模并行 agent + 机器可判定的正确性标准"第一次在开放难题上跑通——Lean 形式化验证提供了不依赖人类评审的闭环信号。这与 AI coding 里的"验证优先于能力"是同一条主线：只有当正确性标准机器可判定时，agent 的产出才是可信的。同日 GitHub trending 主题也恰好是"可信任"——reverify 用确定性工具验证 AI 对代码的断言、bankmcp 把银行数据访问锁进只读边界。
别读过头：形式化验证只在有形式化标准的窄领域成立。通用软件没有等价物，所以这不等于"AI 能自动写出正确代码"。离你最近的可用部分是 Astra 进 Codex——那是今天就能开的东西。

具身 ICL 成新赛道：机器人看一遍演示就会新任务，Scaling 维度从"堆数据"扩到"部署后还能学"

具身智能
来源：量子位（2026-09-06）、Skild AI、Generalist AI；背景工作 RoboTTT（李飞飞 / Jim Fan / Yuke Zhu 等，2026-07-16）

2020 年 GPT-3 靠"看几个示例就会新任务"震动 NLP，同样的故事正在具身领域重演——In-Context Learning。

  • Skild AI · S1：给机器人看一遍任务演示视频，不微调、不做额外 post-training 即可尝试未训练过的新任务；任务时长可达 10 分钟、含几十个操作步骤。关键数据——训练数据仅 1000 小时时语言 prompt 更好，数据规模增大后 ICL 反超；未见任务上加入视频 context 相比纯语言指令提升约 7 倍。
  • Generalist AI · GEN-1.5：同为 one-shot，3–12 秒示范视频，数秒内学会新任务，无需梯度更新，支持人类示范到机器人执行、组合泛化与 Sim-to-Real 迁移。
  • 可可矩阵 COCO Matrix（国内，2026 年 4 月成立）：把 ICL 从后训练前置到预训练阶段，主张"强理解、轻生成"——在条件表征阶段就把动作相关信息提炼出来，同样算力下把动作头压到约 60M 参数，效果仍超过动作头约 1.1B 的对照方案。
反方与边界：① 两家公司均以 demo 形式发布，技术细节未完整公开；② 不要只看示范时长——可可矩阵创始人高宇翔指出，10 分钟视频若全是重复动作，信息密度反而低于一段完整的第一视角任务演示；③ 真正的硬骨头是流式记忆（历史信息持续压缩筛选）与长时序 KV Cache 压缩，这两个都还在内部测试阶段；④ 行业最缺的是"人机教学 / 实时纠偏"数据，连该采集什么都没有统一标准。
为什么值得关注：具身智能的 Scaling 维度正在扩展——过去问"训练时见过多少数据"，现在问"到了没见过的新环境，能不能利用当前 context 快速学会"。连带的是评价指标要换：如果机器人能持续 self-correction，单纯的成功率会越来越不够用，更有价值的是"第一次成功平均耗时"——它对应的正是机器人的教学成本。做具身落地时，这个指标比 demo 视频好看与否更能预测 ROI。

外滩大会：从"翻跟头"到"真干活"，机器人在未改造的人类场景里连续上岗

具身智能
来源：新闻晨报 / 新浪（2026-09-09）、2026 外滩大会具身智能展区

最有说服力的一个场景：凌晨两点的国大药房，货架间距仅 80 厘米、药品密集排列。搭载蚂蚁灵波通用大脑的机器人在不改货架、不重新布线的前提下，自主接收订单、识别药盒、完成分拣，再把药品送回工作台交药师核对打包。

同场其他真作业：

  • 物流：同一套大脑驱动不同形态机器人分拣随机包裹，仅采集 10 小时数据即可连续作业。
  • 工业：眸深智能具身大模型驱动的轮式双臂机器人，识别洗衣机螺栓与装配孔位，自主完成抓取、定位、插入、拧紧。
  • 服务业：擎朗两台人形机器人在洗衣房协同完成取衣→开关洗衣机→折叠整理的长程任务；开普勒人形机器人进入狭小咖啡门店，"充电 1 小时、连干 8 小时"，双臂协同搬运 30 公斤，承担取杯、制饮与清洁。
  • 受限空间：辰行远略的飞行智能体与机器狗进入核电、地铁、水厂等无 GPS、无光、强干扰环境自主巡航。

时间线对比很能说明问题：2024 年外滩大会宇树机器狗还在翻跟头，2026 年 8 月 19 日宇树已登陆科创板成为 A 股首家人形机器人上市公司。本届 40 余家具身厂商集中亮相，核心叙事从"运动能力"彻底切换为"真实工作流程"。

为什么值得关注：行业评价口径变了——从"能不能跑跳翻跟头"变成"能不能在没改造过的人类场景里连续干活"。这给出一条很好用的判据：场景改造成本 ≈ 0 才算真落地；凡是需要改货架、重新布线、贴 marker 才能跑的，本质上还在演示阶段。另外"仅采集 10 小时数据即可连续作业"这个数字，比任何跑分都更接近商业化门槛。
