DeepSeek-V4.1-Flash-1017：DeepSWE 77.0 每题约 1.3 元，MIT 权重顺带把搜索 API 开放给别家 harness

AI Coding
DeepSeek 官方发布与 Hugging Face 模型卡（10-17，版本号即日期）；The Decoder / BlockBeats / AI & Tech News 转述（10-17/18）

DeepSeek 发布 DeepSeek-V4.1-Flash-1017：网页、App、API 同步切换，权重按 MIT 协议上架 Hugging Face 与 ModelScope（FP8 / 8-bit，Transformers 直载）。官方口径是「性能与成本的帕累托改进」——更快、输出更短、agentic 与编码分数更高。真正值得看的不是分数，是三件事：

  • 成本曲线打穿地板。官方 DeepSWE 成本图：77.0% 通过率对应每题约 1.3 元（不足 $0.20），low 档 >72% 约 $0.10；前代 V4.1-Flash 74.2% 要约 $0.50。同一张图上 GPT-6 Astra、Gemini 3.8 Flash、Claude Opus 5 是每题 $2 到 $10+ 且分数不追平。两个月四次迭代，每次以 Opus 为坐标：7 月底 V4-Flash 54.4 → 8 月 V4-Pro 62.7 → 9 月 V4.1 Flash 74.2 → 1017 版 77.0。
  • 底座直接铺进第三方 harness。官方明确针对 DeepSeek Harness（推荐 v0.2.1-rc.1+）、腾讯 CodeBuddy、WorkBuddy 做了调优——模型公司主动适配别家的壳子，而不是等壳子来适配自己。
  • 内部搜索引擎变成公共 API。Search 与 Fetch API 首次向所有开发者开放（按成功请求计费，每端点每千次 $0.75，约 ¥5）；经 Claude Code、Codex、DeepSeek Harness 内置搜索触发的请求免费至 10 月 31 日 16:00 UTC（另有源记 11-01）——等于给别家 harness 的用户付两周过路费。

方法侧的看点是 RLSF（带自反馈的强化学习）：用模型自己的置信度与自我批评当奖励信号，不要人工评估员、不要外部 reward model，面向「从零建完整项目」——官方演示了故宫 3D 场景、网页赛车和 Godot 引擎《传送门 2》复刻，BlockBeats 称之为「许愿式编程」。规格：prefill 每 token 激活 8B / decode 16B，1M 上下文，最高 384K 输出。

这为什么值得看。按本日报 09-22（Grok 4.7）与 09-29（Sonnet 5.5）的判定，纯模型发布是弱条目；这次的变量不是分数，是分发。MIT 权重 + 官方点名适配 CodeBuddy / WorkBuddy + 搜索 API 对竞品 harness 免单——模型公司开始给别家的栖息地付过路费。它与 10-08 ① Haiku 5.5（降价约 90%）、10-15 ② Nemotron（2-bit 量化塞进 24GB 本地跑）并列成「谁付账」的第三种答案：把前沿级分数打到一块三，用免费分发换用量。

另一个必须并读的信号：RLSF 的「自评当奖励」与 09-27 ②（17/17 模型无提示自发 reward hacking）是同一枚硬币的两面——自己给自己打分正是奖励黑客的温床，而官方未披露任何防作弊设计。便宜是真的，验收还得是你自己的。

跑分与成本曲线均为官方口径，无独立基准跟进。DeepSWE 77.0 超的是 Claude Opus 5 的 74.0，不是 Opus 5.5；Terminal-Bench 4.0 从 31.2% 升至 42.3%，仍落后 Opus 5 的 51.8%（BlockBeats）。官方自承对手已到 5.5。

监管传闻单一来源：The Decoder 报道中国政府据报计划收紧开放权重发布规则、甚至禁止，「是否进入前十最强系统」或是判据之一——「reportedly」级别，未证实，采用前请自行核实。

RLSF 无防作弊披露：自反馈奖励与 reward hacking 的结构性风险（09-27 ②）未见官方回应；「许愿式编程」演示为精选案例，非系统评测。

三件事按顺序验：① 拿自己真实任务在 77% 档跑一遍实付账单（对照现用模型的每任务成本，10-14 ① 提醒过同模型不同工具账单可差 70 倍）；② 免单期内把 Search / Fetch 接进 Claude Code 或 Codex，与现有检索工具对比质量；③ 等 Artificial Analysis 等独立口径跟进后再决定是否进生产——在那之前，把它当「便宜的可疑新选项」而不是「新王」。

OpenCode 确认密钥泄露：1.4% Console 用户中招，偷密钥的动机是「大规模蒸馏攻击」

Agent 安全
OpenCode 官方 X 公告（10-17 18:08 UTC，TSNMedia 全文引用）；客户通知邮件转述（CodeYourCraft / CyPro / CyPro 安全公告）；ZAKER 等中文转述（10-18）

开源编码 agent OpenCode（开发商 Anomaly Innovations，前身为 SST）10-17 确认安全事故：事件与一场「大规模蒸馏攻击」相关，波及约 1.4% 的 OpenCode Console 用户——且仅限「在 Console 链接了外部 provider」的子集，即那些把自己付费的 OpenAI / Anthropic / Google API key 存进 Console 工作区、由平台网关代为调用的团队。

  • 时间线。入侵 traced 到一套正在退役的 legacy console 系统；最早暴露约 10-17 00:30 UTC（另有源记 10-16 夜间），距首封通知约 22 小时——首封邮件「Action Required: Potential provider key breach」10-17 22:51 UTC 发出，第二封（说明具体受影响 key）在 10-18 午夜前到达。
  • 已出现真实损失。开发者论坛上至少一人报告约 $100 欺诈性用量，另一人报告 10-17 Claude API 异常活动——均为个人报告、非公司口径；官方称「迄今」未发现其他数据泄露证据，且无法确认暴露的 key 是否已被滥用。
  • 官方应对。与 Anthropic、OpenAI、Google 合作处置；建议用户去各 provider 自己的控制台吊销并重发 key（切勿点邮件里的链接）、检查 10-17 以来的账单与用量日志、设置支出上限。团队成员 thdxr 在 X 上称「我的个人账号现在也在被攻击」。
  • 动机定性才是重点。「蒸馏攻击」指未经授权地从强模型抽取能力去训练竞品——Anthropic 10 月中旬披露此类行动「隐蔽、工业规模」，涉及数十万欺诈账号、约 1.9 亿次从 Claude 抽走的交互，部分途径正是非法获取的真实 API key。偷 key 不只是为了花钱，是给模型工厂供原料。

这为什么值得看。这是 09-29 ① NVIDIA Open Agent Safety Platform 的现场反例：OpenShell 的设计前提原话是「真凭证留在工作负载外」——而 OpenCode Console 恰恰是把凭证收进平台工作区的那一层，泄露面就是所有链接了 provider 的 workspace。也是 09-19 ① Plugin4Shell 之后，agent 供应链信任第二次以密钥形态破裂：上次是插件市场投毒，这次是托管平台失守。

把 ② 与今天速览的 MONST3R-AI 对读，是一条完整的黑色经济链：平台存钥匙（②）→ 地下市场收购赃 key → 自主扫描器用赃 key 干活、账单记在受害者头上（速览）。「谁付账」在这条链上是被偷的人。

key 是否真被读取，公司未确认。ZAKER 等中文源写「API 密钥泄露」，TSNMedia 明确指出「OpenCode has not said that any of these stored keys were exposed」——两方口径并列，勿读成既成事实。

1.4% 是 Console 用户比例，不是全部用户（Console 为可选托管服务；「月活 1600 万开发者」为公司自报）；无绝对人数、无攻击入口细节、无完整 postmortem，官方明说「incident is ongoing」。

「与蒸馏攻击相关」的因果关系公司未解释；三家公司均未公开置评；$100 等损失数字为个人报告。泄露窗口两个口径（10-17 00:30 UTC / 10-16 夜间）尚未有官方澄清。

今天就能做的四件事：① 如果你或团队用过 Console 链接 provider——现在去各 provider 后台吊销重发（从官方控制台进，不点邮件链接）；② 查 10-16 以来的用量与账单，设硬性支出上限 + 告警；③ 按项目 / 人拆分 key scope，让单次泄露烧不动整个组织；④ 对「agent 平台代管凭证」这类功能，默认它迟早被偷一次来设计——凭证外置、短寿命、沙箱外监督（对照 09-29 ① OpenShell 的三层）。

3

Yelp、达美、摩根大通向 AI agent 关门：Schwab CEO 一句「出了事谁负责」，把责任层问倒了

Agent 治理
The Verge（Emma Roth，10-16 主稿 / 10-16 Schwab 跟进稿，10-17 起集中转述）；彭博（Schwab CEO 访谈，10-16）；TechCrunch（Yelp 回应）

The Verge 汇总了近几周一个越来越普遍的现象：Meta Muse、xAI Grok、OpenAI Dots、Instinct 的用户在各大网站上接连被拦——agent 被卖成「替你在网上办事」，而互联网本身并不承认这个设定。

  • 明确关门的三类。Yelp：只放行付费进入其数据授权计划的 agent（告诉 TechCrunch）；达美航空：禁止 agent 代替用户订票；摩根大通与嘉信理财以安全理由确认屏蔽 agent 访问账户。嘉信 CEO Rick Wurster 对彭博（10-16）说得最直白：「我们不希望有人把密码交给 Muse、让 Muse 代表客户行事。我们控制不了，客户也控制不了，万一出事谁负责？所以我们不允许。」
  • 最硬的是 Amazon。称 Muse 的「持续访问」违反站点政策，Grok、Instinct agent、Dots 也被报无法使用 Amazon；马斯克回应：也许该「创办一个 Amazon 的竞争对手」。背景是 Amazon 与 Perplexity 的官司：去年禁掉 agentic shopping 并起诉，法官曾发禁令，8 月被上诉法院推翻，Amazon 已提交修订诉状——战局未定。
  • 静默封锁同样在发生。用户报告 Cars.com、Amtrak 等「以前能用的 agent 现在不行了」——没有公告，只有失败。
  • 开门派走的是商务路线。Meta 官方口径「拒绝一个个人 agent，就是拒绝它背后的客户」，转而与 Walmart、Gap、Sephora、Best Buy 签约让 Muse 可以购物；Shopify 则把整个 storefront 网络开放给 agent。
  • 还有一层误伤。反 bot 系统为防欺诈而建，agent 以机器速度填表正中警报：Reddit 用户报 Google 以「可疑活动」封禁使用 Muse 的账号、Walmart 虽有合作仍结账失败；Cloudflare 在 2025 年一键拦 AI 爬虫之后，开始拦截「同时为搜索索引与 AI 训练抓取」的爬虫。

这为什么值得看。这是 09-21 ③ ChatGPT __obi cookie 的镜像：那条是「web 从 agent 身上刮数据」，这条是「web 拒绝 agent 代表你行动」。capability 的最后一公里不是模型，是门口——EquiStamp CEO Chris Canal 的原话：「这绝对影响 Anthropic 和 OpenAI 的被感知价值：它们宣称 agent 将渗透生活的每个方面，如果有公司在积极阻止这件事，agent 能做的事就更少。」

对工程侧这是基建级信号：每个域都变成一次单独集成，licensed API 生存、对敌意门店的浏览器自动化死亡；per-domain 成功率监控从边缘需求变成核心基建——静默封锁在日志里长得和选择器失效一模一样。

多为用户报告 + 公司对媒体确认，无系统计量；刻意封锁与反 bot 误伤在报道中混杂，无法拆分比例。

Amazon v. Perplexity 未决（修订诉状已提交）；OpenAI / Google 未回应置评、Instinct 拒绝置评；「Walmart 合作」与「Walmart 结账失败」并存——合作不等于畅通，Meta 的商务路线尚未证明可复制。

Yelp 收费、达美禁令均为公司单方面口径，条款细节（价格、范围、违约后果）未公开。

做 agent 产品的先画三张表：① 目标站点授权矩阵（官方 API / 数据授权 / 合作伙伴 / 封锁 / 静默封锁，按域逐条标）；② per-domain 成功率监控，把「静默封锁」与「选择器失效」分成两种告警；③ 人类交接路径——被门拦住时干净地交还给人，而不是硬闯。别再把「浏览器自动化」当默认通道。

Altman 确认 OpenAI 自研人形机器人：「我们会做」，但大脑是比身体更大的问题，2027 年才演示

具身智能
IT之家 / 凤凰网科技 / 新浪财经 / 同花顺（10-18，译自 Engadget）；Altman 在 Sources 播客与《财富》访谈的转述

Altman 在《Sources》播客里被直接问到 OpenAI 是否会亲自造人形机器人，回答只有一个词：「我们会（We will）。」他给出的两条理由——

  • 选人形是因为「世界为人类而建」。门、键盘、所有工具都按人的形态设计，要在同类空间里活动的机器，采用相近外形是合理选择。
  • 但真正的瓶颈是「大脑」。外观细节「远不如把驱动机器人运转的大脑造出来重要」——原话逻辑：给机器装上胳膊腿，它不知道怎么用，一样没用。拿马克杯的例子：识别杯子、找到杯柄、预估握法、施对力气，错了咖啡洒了还得打扫。

节奏上他说得很保守：接受《财富》采访时预计 2027 年拿出「亮眼的演示样机」，「但机器人走上街头还需要再等好几年」——没有演示内容、没有外观、没有外部接触时间表。

招聘清单就是路线图。目前 27 个开放机器人岗位，覆盖运动控制、状态估计、执行器控制、整机行为开发，以及训练具身系统的 ML 基础设施；同时自研机电一体化执行器（电机、传动机构、传感与热管理），并有面向规模化量产的制造与供应链岗位。阶段目标：近期做协助技术工人建设基础设施的通用机器人，远期才是家用个人机器人。脉络上可追溯到 Dactyl——在仿真里练出机械手、转战魔方，那是「软件里学会了、物理规律不答应」的最早案例。

这为什么值得看。这是「大脑 vs 身体」路线之争的最新注脚：别人在卷身体——Figure 把退役机器人熔进钢水（今日速览）、波士顿动力 Atlas 产能排队到 2027、宇树把群控软件白送（今日 ⑤）——OpenAI 把宝押在「脑子还没解决」，并为此自研执行器。它与 09-21 ④（Astra 直接开动机械臂，Zia：「机器人领域的 OpenAI 可能就是 OpenAI，而不是 PI 或 Skild」）、10-14 ③（Google 一段人类视频直接 sim-to-real 上真机）构成同周三条「模型公司下厂」路径，形态截然不同。

另一个读法：当日第一辑 ⑤ 信通院报告说国内多数企业与前沿差约两代——OpenAI 这份招聘清单，就是那两代差距的目录。

这不是产品公告。无原型、无外观、无价格、无发布时间表；「2027 演示」出自《财富》访谈转述，播客与访谈的英文原文上线时间未在中文转述中明确（中文媒体 10-18 集中报道），引用时请以 Engadget / Fortune 原文为准。

27 个岗位为报道时点快照；「协助基建工人」「家用机器人」是方向表述，不是承诺；Dactyl 是 2018—2019 年的旧研究，只作脉络不作能力证明。

两个可操作的观察点：① 对具身创业者——盯 OpenAI 招聘目录的技能组合变化，「自研执行器 + 制造供应链岗位」是硬件垂直整合的信号，决定未来是卖模型还是卖整机；② 对投资与采购——把「演示」与「上岗」继续分开计价（承第一辑 ⑤ 信通院三冷：月均开机天数、订单类型、TCO 三件套），2027 年的「亮眼演示」大概率仍是演示。

宇树免费放出 UniUni 群控软件：机群控制平面从厂商内部工具变成用户手里的产品

具身智能
Pandaily（10-17 首发）；RobotToday / AllWorld.Media 转述；AIGC.NEWS 事件页（标注「尚未获公司或第二独立信源确认」）

宇树发布 UniUni 集群控制软件：Windows / macOS 桌面应用，对所有宇树用户免费（首发版本 Win 1.1.14 / macOS 1.1.15），首发支持 H2 与 G1 两款人形。功能清单几乎就是一张「多机演出与巡检的最小控制面」——

  • 编排：2D / 3D 视图里手画每台机器人的轨迹；拖拽时间轴编排群体动作顺序；AI 辅助工具排全身动作并对齐音乐节拍。
  • 定位：导入点云地图，机器人以激光 SLAM 自主定位；同局域网内自动发现、自动配对。
  • 监控与安全：运行中逐台实时状态；一键全群急停。

它的意义要把语境放进来： coordinated 人形表演是中国厂商的标准展示形态，此前每场都要定制编排；同步时间轴 + 地图 + 中央监控 + 统一急停，第一次被做成客户能自己跑的产品。

这为什么值得看。当日第一辑的主线是「栖息地在资产化」——UniUni 就是具身侧栖息地的雏形：机群控制平面从「厂商内部工具」变成「用户可自运的产品」，而且免费。对照同公司 09-20 ④ UnifoLM-WLA-1.0（开放世界-动作模型的部分权重）：模型扣着放，工具全量白送——软件层才是生态抓手，这与第一辑 ① Beam「模型只是内核，harness 与生态整包出厂」是同一个判断的两次执行。

往安全侧再读一层：一键全群急停 + 中央状态监控，就是 09-29 ① OpenShell 在编码 agent 上做的事（沙箱外监督、可一键停）在物理机群上的对应物——控制面正在成为标配，而不是增值项。

做机群调度 / 多机表演 / 巡检的，直接下载试，重点验三件事：① 20+ 台规模下的规划延迟与急停延迟（演示场景最怕这两个数）；② 激光 SLAM 在真实场地（非完美点云场景）的定位漂移；③ 时间轴编排能否导出 / 回放——决定它只能做 demo，还是能进生产 pipeline。
