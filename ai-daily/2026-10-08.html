Anthropic 发布 Claude Haiku 5.5：平均成本砍掉约 75%，第一次让「并行试一百种方案」比「慢慢想一遍」便宜

AI Coding · 模型定价
来源：Anthropic 官方发布说明《Introducing Claude Haiku 5.5》（2026-10-08）与 Haiku 5.5 System Card · 交叉参考：站长之家 10-08、每日经济新闻《全球科技早参》10-08、Web AI News 10-08、releasebot 收录的发行说明全文

Anthropic 在 10 月 8 日把家族里最轻的那一档正式换代，官方口径是「迄今最快、成本最低、能力最强的小模型」。真正值得读的不是这句口号，而是它的计价结构和那个藏在迁移指南里的三十个百分点。

  • 两段计价，分界在 10 万 token 的 prompt：不超过 10 万的部分，输入 每百万 0.10 美元、输出 0.50 美元，官方称比 Haiku 4.5 的 1 美元 / 5 美元低 90%；超过 10 万的部分降到 0.50 / 2.50，官方称降 50%。缓存读 0.01、五分钟缓存写 0.125，批处理再减一半。约 90% 的 Haiku 4.5 请求落在 10 万 token 以内。
  • 而这些换算成「平均运行成本降约 75%」时，前提是按新分词器重算过——官方明确说同样的文本在新分词器下会比 Haiku 4.5 多算约 30% 的 token。降价与涨价是同一件事的两面。
  • 第一个带可调档位的 Haiku：从 Low 到 Max 共五档，API 默认 Medium，自适应思考默认开启。这意味着「便宜模型也能在需要时多想两步」第一次变成了拨钮而不是版本选择。
  • 上下文 100 万 token，单次输出上限 12.8 万（批处理 beta 到 30 万），支持文本与图像输入，知识截止 2026 年 6 月，模型 ID 为 claude-haiku-5-5，同步上线自家平台、AWS、Google Cloud 与 Microsoft Foundry。
  • 顺手改了隔壁的价格：Sonnet 5.5 的缓存读价格减半到每百万 0.10 美元，官方称多数 agent 任务的运行成本因此再降约 20%；同时给 Claude Max 与 Team 订阅者新增月度 API 额度。
  • 官方自报基准（见 system card）：OSWorld 2.1 离线子集 72.4%（GPT-6 Luna 48.9%、Haiku 4.5 15.7%）；Terminal-Bench 4.0 39.2%（Luna 16.4%、Haiku 4.5 为 0）；FrontierCode 1.1 主榜 46.4%（Luna 42.4%）；HLE 无工具 45.9% / 有工具 57.4%；GDPval-AA v2.1 得 1620（Luna 1437、Haiku 4.5 735）。
  • 但同一张表里有句话更重要：Sonnet 5.5 每一行都仍然领先，Terminal-Bench 4.0 是 70.6%。Anthropic 自己也写明，复杂的 agent 编码仍然推荐 Sonnet 5.5 与 Opus 5.5。
  • 产品定位因此很清楚：做 Opus 5.5 与 Sonnet 5.5 手下的子 agent，以及摘要、压缩、分类、数据库查询、实时客服、浏览器操作这类频率高、单价敏感的任务。官方举的例子是 Rogo——让 Haiku 5.5 的子 agent 去抽取 10-K 报表里的收入行，大模型负责做整套材料；Asana 的工程师则称任务完成延迟下降超过 30%、每个 agent 回合的推理最高快 2.5 倍。
  • 迁移有硬坑：非默认的 temperature、top_p、top_k 会直接返回 400；budget_tokens 换成自适应思考加 effort 档位；预填回复不可用；格式要求要改用结构化输出；电脑操作要换到新工具集；Priority Tier 暂不支持。官方在 Claude Code 里留了一句 /claude-api migrate this project to claude-haiku-5-5 让它自己改。

为什么值得关注 —— 这条要放在昨天那条主线的正对面读。昨天这栏的结论是「产出已经不是瓶颈，背书才是」；今天这一步，是把「探索」这件事重新定价了。

过去一个编码 agent 遇到难题，路径基本是「让它想久一点」，代价是付贵模型的钱、等更久。Haiku 5.5 把另一条路变得可算了：同样的预算可以让十个便宜的实例并行各试一种写法，最后由大模型收敛。官方转述的一个演示很直白——同一个装鸡蛋架子的任务，Opus 5.5 单干用了 3 分 37 秒、试了 25 种方案、花 0.47 美元；带 10 个 Haiku 5.5 子 agent 后只用了 58 秒、试了 86 种、花 0.14 美元。钱少花了一半，时间是原来的四分之一，试的宽度是原来的三倍多。

把它翻译成研究者的话：搜索的宽度第一次比深度便宜。在此之前，编码 agent 的经济结构更接近一个耐心的专家；在此之后，它更像一轮并行的发散加一次收敛。这对所有依赖「让模型多想一会儿」来提分的流程都是一个提醒——那个「一会儿」现在有了替代品的报价。

还有一个不能漏的数字：新分词器多算约 30% 的 token。这既是「75% 是平均值而不是每个 prompt 都一样」的技术原因，也是一条采购纪律——任何基于 Haiku 4.5 做的成本预估今天全部作废，必须拿自己的真实语料重算。

三条立刻可落地

① 先用自己的 prompt 重算 token，别直接信「降 90%」。三十个百分点的分词差异在长上下文任务上能吃掉大半收益；迁移前用真实请求跑一遍计数与 unit cost。

② 扫描一遍代码里非默认的 temperature / top_p / top_k。这三项现在会直接返回 400，是本次升级最容易在生产上炸的一个点。

③ 把「单调用单价」换成「单任务总成本」来评估。子 agent 并行会成倍增加调用次数，判断是否划算要看整条任务的钱和时间，而不是每百万 token 的报价。

全部性能数字为 Anthropic 自报：OSWorld、Terminal-Bench、FrontierCode、GDPval 的成绩均出自其 system card，未见第三方复现；比较对象（GPT-6 Luna、Haiku 4.5）由 Anthropic 自行挑选。

演示与证言要分开看：上述「58 秒 / 86 种 / 0.14 美元」来自中文科技媒体对官方演示的转述，本文未核到 Anthropic 的一手演示页面，采用前请核实；Asana、Rogo、AlphaSense 等客户评价是厂商挑选的推荐语，AlphaSense 的「每周约 800 万次调用」为企业自述。

「平均降 75%」的三个限定：一是按 token 加权平均而非每个请求都省这么多；二是 90% 与 50% 是不同段落的降幅，不要混用；三是基于公开定价，未含任何批量折扣或企业协议。

发布方也是受益方：Anthropic 同时销售被推荐搭配的 Sonnet 5.5 / Opus 5.5，「复杂任务仍请用贵的那档」这一建议与其商业利益同向，读表时请把这一点算进去。

2

Google 的 Gemini 4 Argon 把单次输出上限从 6.4 万提到 100 万 token，代价是今天除了 650 家安防守卫者之外没人能用

AI Coding · 长周期任务
来源：Google DeepMind 发布材料与了一手转述（technewshub、TUN 记为 2026-09-30 首发）· 今日集中解读：腾讯研究院《AI 速递 20261008》、钜亨网、TechNews Hub · 交叉核证：Vals AI Finance Agent v2 榜（2026-10-01）、Artificial Analysis 智能指数

这是 Gemini 4 世代的第一款旗舰，Google DeepMind 资深副总裁 Koray Kavukcuoglu 把它定位成「前沿智能新时代的开端」。今天它在中文与港台媒体上被集中重读，原因很实在：它把军备竞赛从输入端搬到了输出端。

  • 最硬的一个规格：单次响应输出上限从上一代的 6.4 万 token 提到 100 万。过去几年所有模型的上下文竞赛都发生在「能吃进多少」，这次动的是「一次能吐出多少」——理论上足够把一次完整的代码库迁移放进一条不被截断的轨迹里。
  • 内部已经在用它做这种事（均为 Google 自述）：数千名员工用于调试与大规模软件工程；agent 正在把 C 与 C++ 代码库迁到 Rust，包含 Fuchsia Zircon 内核里超过 80 万行；给开源视频解码器 libgav1 生成的 Rust 版本比现有 Rust 移植快 2.7 倍且视频输出一致；跨数据中心识别内存优化，已释放 300 TiB，预计总量可达 500 TiB 到 1 PiB；量子计算研究中对某算法优化的公开基线提升 40%。
  • 基准成绩（除一项外全部自报）：DeepSWE v1.1 77.9%（长周期真实软件工程）；CWE-bench v1 68%（漏洞修补，并列第一）；LVBench 91.7%（长视频理解）；Zapier AutomationBench 51.3%；APEX-Agents 82.4% ±4.3（Sonnet 5.5 为 75.5%、Opus 5.5 为 73.5%）。Google 称在 18 项评测中有 12 项超过 GPT-6 Astra 与 Claude Opus 5.5。
  • 唯一的第三方独立印证：Vals AI 的 Finance Agent v2 榜单在 10 月 1 日独立地把 Argon 排在第一，得分 65.40%。其余各项没有独立复现。
  • 也存在反向证据：在 Artificial Analysis 的智能指数上 Argon 仍落后 Claude Opus 5.5；GPT-6 Astra 在若干软件、科学终端与 computer-use 任务上仍领先；Opus 5.5 在 terminal-agent 与后训练基准上领先。
  • 价格目前只是一个报价单：促销价每百万输入 2 美元、输出 10 美元，之后回升到 4 / 20，缓存输入 95% 折扣。按 Vals 的每任务成本口径，约合 每任务 1.99 美元——GPT-6 Astra 约 3.26 美元、Claude Opus 5.5 约 5.98 美元。
  • 但今天几乎没有人能用得上：Google 选择先把它交给参与 Fairwind 计划的全球 650 多家安防守卫者与政府机构，付费 API 客户与 Google AI Ultra 订阅者排在下一批，没有公布日期。中文一线的解读更直白：目前只对网安防御团队开放，真实编程任务上仍然吃力。

为什么值得关注 —— 把这条和今天 ① 并排放，是整个今天的重点。同一天，两家实验室对「长周期任务该怎么跑」给出了方向相反的答案：Anthropic 说横向铺开（很多个便宜的并行探索，最后收敛），Google 说纵向拉长（一次航程跑完，中间不切断）。

而横向与纵向各有对应的失败模式：并行的失败是探索之间不共享记忆，每一次都从零想起；长航程的失败是跑偏之后没有回头，因为「一次性完成完整重构」这个架构天然没有检查点。Google 没有公布任何关于中断、纠错或回退率的数据——100 万输出 token 听起来很大，但它是否等于有效的长周期工作，目前无人验证。

更值得注意的是这次开放顺序的选择。一个主打「软件工程与大规模代码迁移」的模型，第一批用户是安防守卫者而不是开发者。合理的解释是 CWE-bench 68% 这个数字本身就是它的准入理由—— autonomous vulnerability remediation 是最容错的场景，找漏补漏错了也不至于毁掉业务。这是一个值得记的工程判断：长周期能力先在允许失败的场景里交付。

最后是可 Finance 层面对照的一点：① 是让便宜的东西更便宜（继续往下走），② 是让最贵的东西每任务只花 1.99 美元（也是往下走）。两条同日发布，说明 2026 年秋天的价格曲线还远没见底。

两条跟踪建议

① 盯 GA 日期而不是盯榜单。它没有公开可用日期，非 Fairwind 成员今天既拿不到也测不了；在此之前任何「Argon 改写某某工作」的说法都不成立。

② 如果你在评估长周期编码流程，把「有没有检查点」当成硬指标。100 万输出 token 的价值取决于中途能否被纠回来；供应商若不提供回退、重试与中断率数据，就把它当成实验室结论。

日期分层（引用前必读）：首发时点在二手源之间不一致，TUN 记为 2026-09-30，另有英文源的 10 月 4 日综述已收录；中文一线（腾讯研究院 AI 速递、极新早报、太平洋科技日报）则在 10 月 8 日集中解读。本期的增量是今天的中文解读与 Vals AI 的独立佐证，不是模型本身的首次发布。

除 Vals AI 一项外全部为 Google 自报：80 万行迁移、2.7 倍、300 TiB、量子优化的 40% 提升与 CWE-bench 的并列第一，均无第三方复现；上述 Rust 迁移发生在 Google 自家代码库，质量标准由自己定义，不等于外部仓库的可迁移结论。

每任务 1.99 美元是 Vals 的成本口径，不是你的 API 账单；促销价与正式价相差一倍，不要拿促销期的数字做长期预算。

计价口径提示：本条的 1.99 美元按 Vals 的「每任务」口径，与 ① 的「每百万 token」口径不是同一个单位，两者不可直接换算比较。

微软的答案最彻底：例行编码改由本机 137B 模型承担、不计推理费，同 MXC 容器沙箱脱离 beta 正式可用，但三种模式里留了一个「记录但不拦」

AI Coding · 本地推理 / Agent 沙箱
来源：Microsoft Windows & Surface 发布会（2026-10-07，旧金山，Satya Nadella、Pavan Davuluri、黄仁勋同台）· 官方文档：blogs.windows.com《Microsoft Execution Containers: Policy-driven containment for AI agents》、blogs.nvidia.com · 交叉参考：HotHardware 现场报道、Superpower Daily、HuggingNews 10-07、Chinaz 10-08、发布会现场 X 帖

微软在旧金山办了一场把 NVIDIA CEO 请上台的 Windows 与 Surface 发布会。如果只看标题它会像一场硬件发布会，但真正在这里发生的事有两件：例行编码被搬下了云，以及agent 的沙箱结束了公测。

  • MXC（Microsoft Execution Containers）正式可用：一个策略驱动的 containment 层，由企业指定 agent 可以用哪些文件、哪些网络位置、哪些工具，运行期间 Windows 拦截其余一切。隔离级别从独立进程、独立会话一路到虚拟机与云 PC。
  • 三类容器：process container 支持 Windows 11、macOS、Linux；session container 仅 Windows 11，把 agent 的桌面、剪贴板与输入同人的活跃会话隔离开；Windows 365 支持同步 GA，让 agent 工作负载跑在云 PC 上。
  • 三种模式值得单独记：learning 阻断未授权访问并记录；permissive 记录本应被策略拒绝的访问但仍然放行；enforcement 直接阻断且不产出活动报告。换句话说，「看得见」和「拦得住」在产品里是两个显式开关，默认不是同一个东西。
  • HydraFusion（发布会演示时仍以 Project 冠名）：GitHub Copilot 的多模型编排系统，逐请求评估后选择最省的模型起草，必要时才升级。关键动作是把例行编码任务从 Anthropic 的 Claude Haiku 4.5 切到本机运行的 MAI-Code-1.1 Flash——137B 总参、6.8B 激活、3-bit 量化但保留 256K 上下文，微软称在 SWE-Bench Verified 与 Terminal-Bench 2.1 上与全精度同分，本地调用不产生推理费用。
  • 硬件是这个方案的地基：Surface Laptop Ultra 起售 2,599 美元、Surface RTX Spark Dev Box 5,999 美元（11 月出货），均基于 NVIDIA RTX Spark（Arm 架构 + Blackwell GPU，处理器与图形共享最高 128GB 统一内存）。微软自报的对比数字：出图比最新 MacBook Pro 快至 4.3 倍、首 token 快 2.1 倍、视频生成快至 6.2 倍。
  • 同一场发布还提到：Microsoft AutoPilot 被称为第一个「企业级长运行 agent」；Agent 365 作为 IT 管控平面与 Entra、Defender、Purview 打通；llama.cpp 正在上 Windows ML；Meta 的 Muse 年内以原生应用登陆 Windows； DeepSeek V4 Flash 与 NVIDIA Nemotron 本地模型在途中；Perplexity、Hermes、OpenClaw 的本地 agent 同日上线 Windows。
  • 治理部分没有同步交付：Entra 对 agent 行为的归因、Agent 365 对本地 agent 的控制、Intune 对 Win11 process container 的策略管理，全部标记为 coming soon。

为什么值得关注 —— 这是同一个「谁付算力钱」的问题被用第三种方式回答了。前两条是在单价上竞争；微软这一步是直接取消单价。

时序上的巧合很有意思：GitHub Copilot 今天为止的例行编码还在调 Anthropic 的 Claude Haiku 4.5，而 Anthropic 恰好在今天把 Haiku 5.5 降价约 75%。微软选择的回应不是谈判更好的价格，而是把这部分负载搬到本地，理由是这笔钱为零。代价也很清楚——这份零需要一个 2,599 美元起的前置门槛。竞争维度由此从「每百万 token 多少钱」变成了「你愿不愿意先买台机器」。

对从业者而言，MXC 那三个模式才是本条最值钱的部分。learning 与 permissive 的存在，说明微软承认企业在落地初期并不知道该给 agent 什么权限。这不是缺陷而是一个务实的迁移路径：先只记录看清它到底碰了什么，再收紧。但同样要清醒：permissive 模式下策略只是建议，边界在本\b机、在企业，不在这层容器里。

① 把 agent 权限当成一个要先观测后收紧的流程。先用 learning 模式跑一到两周，拿到它实际请求的资源清单，再写策略；直接上 enforcement 大概率会打断业务。

② 明确记录当前处于哪种模式。permissive 下产生的越界访问会被记录但不会拦，把这个事实写进 agent 的上线评审单，别让它被误读成「已有隔离」。

③ 算本地方案时要把硬件折旧摊进去。「本机不计费」成立的前提是机器已经付过钱；按 5,999 美元的开发箱做三年折旧，远不等于零成本。

HiPHI 端出 617.5 小时亚毫米级光学动捕数据，其中 245.7 小时带同步物体网格，已迁到 Unitree G1 实机

具身智能 · 数据集
来源：HiPHI 白皮书（IEEE Spectrum 与 Wiley，2026-10-07）· 发布方 Noitom Robotics · 交叉参考：RobotToday《HiPHI Dataset: Advancing Human Motion and Object Interaction for Humanoid Robots》、GoKawiil 10-07、Hello Marvis AI Today 10-07、IAExpertos 技术解读

与今天 ④ 同一天，另一拨人给出了具身数据问题的完全相反的答案。这一家的主张是不靠规模靠精度。

  • 规模与精度：全身人体运动数据合计 617.5 小时，采用光学动捕，精度为亚毫米级。
  • 其中 245.7 小时是人-物交互，并且同步记录了物体的轨迹与 3D 网格。这一点很关键——互联网视频有 diversity 但没有精确物理状态，而只有理解了物体怎么被推动、被形变，才能教会机器人搬、推、拉这类动作。
  • 用 FrameNet 组织采集：FrameNet 本是语言学框架，把人类动作拆成施事、受事、工具、结果等语义角色。HiPHI 拿它当采集的方法论骨架，系统覆盖而不是随机录制，避免出现「录了一万小时但全在同一个动作附近」的情况。
  • 不只是数据集：白皮书同时给出了一套度量运动多样性与交互接地（interaction grounding）的基准套件，让后续的数据集可以横向比。
  • 闭环：论文报告了在该数据集上训练的强化学习策略，并迁移到实体 Unitree G1 人形机器人上部署（sim-to-real）。
  • 它对标的那个缺口说得最清楚：互联网视频有多样性但抓不到精确的物理状态；传统实验室动捕有精度但动作谱很窄。HiPHI 想同时占住两头。

为什么值得关注 —— 今天 ④ 与 ⑤ 是具身智能当前最大的那场未决争论，被同一天摆到了台面上：要多样性，还是要物理精确。Mecka 押前者（野外、放大规模、有人付钱录制），HiPHI 押后者（实验室、光学动捕、亚毫米 + 物体网格）。

这不是第一次见到这场争论。10-05 的 Runway Praxis-1 对 FieldAI 就是它的上一幕——前者押网络视频预训练，后者押物理先验、估值报到 100 亿美元。今天的区别在于：两方都拿出了可在实机上验证的交付物（一个给出 EgoVerse 的跨实验室复现，一个给出 Unitree G1 上的 sim-to-real），而不是只端出一批数据。

还有一个容易被忽略但很妙的细节：HiPHI 用一套语言学框架来组织运动数据。这件事的含义是，采集分布被一件外部语义骨架约束住了——动作不再是「录到什么算什么」，而是「语义角色表里还缺哪一类」。这与今天 ① 里「用结构化输出替代自由生成」在方法论上是同构的：都是先定好答案的形状，再去看里面填了什么。

10 月 2 日首发、今天被行业日报二次传播。五档规格 0.8B / 2B / 4B / 9B / 27B，权重与三种 GGUF 量化（Q8_0、Q4_K_M、BF16）全部开放（详见其 GitHub 与 Hugging Face 页面）。它切的口子很窄：agent 执行过程中反复出现的那类判断题——下一步点哪个按钮、调哪个工具、当前任务是否完成、这张工单该给哪个团队。候选集往往已经确定，而每一步等待都会累积。做法是接收当前状态与候选项，一次前向同时返回多个问题的判断及选项概率，不逐字生成答案文本。延迟：单张 H200、BF16、短请求下通过本地 HTTP 测得，一次回答三个问题——0.8B 12.2 毫秒、2B 15.5 毫秒、4B 26 毫秒、9B 35.7 毫秒、27B 102.3 毫秒。成绩：独立的 Decision Index 0.2.1 上 27B 得 63.88（Jev 1.13 为 57.91），38 项基准中 31 项更高；上海 AI 实验室发 Intern-Decision 时用的七项评测组合上，27B 平均准确率 91.82%，高于 Jev 的 88.74% 与 Intern-Decision-4B 的 90.02%；JevBench 答对 208/231，Hard 子集的 111 道难题少错 8 题。团队称研发与验证全程只用 3 天，靠自家的 Auto Research 闭环（RSI 体系的一环：AI 参与「假设—实验—验证—新假设」的循环，研究目标、评价标准与关键取舍仍由人类研究员把关）。为什么值得看：它是今天 ① 那条思路的极端版本。Haiku 的 effort 档位是把思考变便宜，它是直接取消了思考的输出形式。当 agent 每一步都在等大模型吐字，把「候选已定的判断」外包给一个 26 毫秒的模型，是第三条降本路径。边界：全部成绩为公司自测自述；Decision Index 0.2.1 被描述为「独立」，但该评测的运营方本文未核到；延迟为特定硬件与短请求下的响应时间，不含排队，与端到端延迟不是一回事；「3 天完成研发」为公司自述；对照组是它自己选的。

智元远征 A3 接入网易云音乐：10 月 15 日起可语音点歌，而公开播放仍要另办商业授权

9 月 30 日宣布的合作，今天经行业日报二次传播：自 10 月 15 日起，用户可以对远征 A3 说出歌名或歌手，由系统检索曲库、完成账号鉴权并通过机器人本体播放，无需外接设备。首阶段开放的核心功能是语音点歌，覆盖歌曲检索、账号鉴权、播放控制三条链路，并已适配嘈杂环境唤醒、弱网重试与多用户并发；个人用户经产品授权使用，账号登录等能力将按产品交付版本与网易云音乐的授权范围逐步开放。横琴长隆飞船乐园部分点位已开展音乐交互试点，但若用于公开播放、巡游配乐或经营性演出，仍需另行确认商业授权。后续方向包括 music to gesture 生成式动作模型、AI DJ 与随心伴唱。为什么值得看：这条的价值不在能力而在边界——机器人把音乐「播放」出来是需要另行授权的商业行为。人形机器人一旦进入文旅与 C 端场景，每一个内容型交互背后都可能挂着一条版权与表演许可链。它与昨天 ③ 那条 Photopea 事件是同一种张力的两端：昨天是代码被合法地重新表达了一遍，今天是一段音乐被调用也要重新谈一遍许可。具身化的副作用是，「使用」在物理世界里会变成「表演」。边界：10 月 15 日为计划开放日，届时是否如期未能验证；功能边界取决于两家的授权范围，公开材料均未给出清单；试点属产品测试性质。
