  • 2.把 agent 的「手」和「脑」拆开：谷歌用隔离微虚拟机把密钥挡在沙箱外，斯坦福给每个动作装上可回滚的提交——让 agent 犯错之后还能收场
  • 3.一次压缩之后 agent 记住了 77% 的决策，却只留下 0.2% 的 shell 命令：43 次真实对话的比对，暴露了长期任务最难查的一种失忆
