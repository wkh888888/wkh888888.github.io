Obsidian：把笔记还给你自己硬盘的「第二大脑」

它的核心不是双链也不是图谱，是「你的笔记就是一堆 .md 文件」—— 这个决定让所有花哨功能都变得可逆。

先讲它最值钱的那个决定

Obsidian 的 vault（库）本质上就是你硬盘上的一个普通文件夹，里面是一堆 .md 文件。没有私有格式、没有云端数据库、没有账号才能打开。

这意味着：

  • 关掉 Obsidian，用 VS Code 照常读写，一份笔记都不损失；
  • 想同步就自己选：iCloud、Git、Syncthing、网盘，或者花钱用官方 Sync；
  • 哪天 Obsidian 不做了，你的知识库还在，格式是通用的 Markdown。

很多人把 Obsidian 当成「有图谱的笔记软件」，其实真正让它长期可信的是这个决定。

它擅长什么

双向链接与图谱：[[另一篇笔记]] 就能建立链接，反向链接面板自动收集「谁引用了我」。写技术笔记时特别有用 —— 积累几十篇后，图谱和反向链接能帮你发现自己早就把某件事写过一遍。

插件生态：社区插件上千个。常用的几类：日历（Daily Notes）、看板（Kanban）、任务管理（Tasks）、导出（Pandoc / 站点生成）、模板（Templater）。装多了会拖慢启动，建议克制。

Markdown 原生：代码块、表格、Callout、嵌入图片和 PDF 都支持，写起来和 GitHub README 手感一致，复制出去也不丢格式。

多端可用：桌面免费，手机端也有（同步方式自选）。

它不擅长什么

  • 协作。它是单人的。多人编辑请找 Notion / 飞书文档。
  • 开箱即用。默认状态下它很朴素，好看和好用基本都要靠插件与主题调 —— 有人管这叫可玩性，也有人管这叫折腾。想「装上就能用」的人会失望。
  • 移动端体验弱于桌面。手机上更适合速记和查阅，不适合重度整理。

怎么用才不容易放弃

我的建议是先做减法：

  1. 只建一个 vault，不要按项目分好几个库（跨库链接体验差）；
  2. 文件夹结构保持两层以内，靠链接而不是目录来组织；
  3. 日用只开三四个插件：Daily Notes + Templater + 一个任务类插件；
  4. 同步优先用 Git（有版本历史，还能在提交里看笔记演化），其次 iCloud，最后才考虑付费 Sync；
  5. 别在插件和主题上花超过一晚上 —— 那些时间不会变成笔记。

上手

官网下载即用，个人免费（商业用途需授权）。先别装插件，写两周纯 Markdown 笔记，等你确实感到「找不到东西」了，再去装第一个插件。
