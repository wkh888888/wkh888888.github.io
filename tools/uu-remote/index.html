UU远程：装完就能用的 4K 远控，代价写在协议里

先说清楚它不是什么

写完 RustDesk 再写 UU远程，对照会特别清楚。它官网上那句「真 4K、真免费、真好用」很容易让人以为它是「更好用的 RustDesk」，其实两者的差别是路线级的：

  • 它不是开源软件，也不能自建。没有公开仓库，官方《软件许可及服务协议》明确写着网易享有全部知识产权，用户不得复制、修改、挂接运行或创作衍生作品，甚至「不得使用非网易公司提供的插件、外挂或非经授权的第三方工具/服务接入」。上一期 RustDesk 那句「可以自己写一套 rendezvous/relay server」，在这里是完全相反的方向。
  • 它不是一个纯工具，是一项账号服务。主流程要在各端装客户端、用同一个网易账号登录，设备列表、连接历史、云键位都挂在账号上；不是「发个 ID 就完事」的独立程序。
  • 它的「免费」不是承诺，是现状。协议第 5 条明确保留把免费服务变更为收费、调整收费标准的权利，第 6 条保留在服务中投放广告的权利，4.2 条不保证旧版本继续可用，4.4 条保留修改功能、中断服务且无需担责的权利。这几条是这期最值得读的内容，下面单独展开。
  • 它不只是办公远控。前身叫 GameViewer，从 UU 加速器的游戏网络里长出来的，游戏串流、键位映射、手柄回传才是差异化最大那块。
  • 它不是「端到端加密 = 万事大吉」。被控端要拿系统权限、装常驻进程；加密解决传输，解决不了「谁有权连上这台机器」。

预期摆正：它把远程桌面做到了「装完登录就能用」，代价是把中间那一层、账号、以及一部分设备信息，都交给了网易。这不是贬义，是选择。

数据来源说明：这一期没有 GitHub 仓库可查，一手材料是官网 uuyc.163.com、官方《软件许可及服务协议》与《隐私政策》、官方产品页，加上本机 App 实测。网上大量「1ms 延迟」「单文件 10GB」「300MB 传 55 秒」出自第三方推广稿，没有官方背书，本文不采用；官方自己给的规格也一律标成「官方口径」，不代表我跑过实测。

它解决什么痛点

  • 免费版被功能阉割：向日葵、ToDesk 这类国内工具的免费额度常卡在画质、帧率、文件大小、多屏上；UU远程把这些标成免费开放，是它最直接的杀伤力。
  • 公网串流门槛高：自己搭 frp / 打洞 / 端口映射对普通人是硬门槛；它用账号 + 专网把这些全部藏掉，异地即装即用。
  • 国内跨网远控的延迟：官方产品页说依托 300 多个节点机房构建高速专网，这是它相对境外公共服务器的天然优势。
  • 手机/平板想玩 PC 游戏、当副屏：大包体游戏不用在移动端重下，平板能当无线副屏，手柄和键位方案是现成的。
  • 帮家人修电脑：ID + 验证码快速连接；官方还提供一个 Windows 精简版单文件 exe，对方不用安装登录、双击给码即可（这条来自网易自家内容号，不是官网功能页）。

我认为最值钱的两个：把公网串流的配置成本压到零（这是绝大多数人真正卡住的地方）和防窥屏 / 被控端静音（在办公室、宿舍这种场景里，它比多 30 帧实用得多）。游戏键位方案是加分项，但只对该场景的人成立。

平台与安装

官网 uuyc.163.com 下载各端客户端，同账号登录；被控端要放行系统权限（官方博客特别提示 macOS 的辅助功能权限）。办公/协助场景走「我的设备」列表点选，临时协助走 ID + 验证码。

本机实测（macOS 26.6.2 / arm64）：

项 实测值
应用 /Applications/UURemote.app，4.42.0（build 625），185 MB，2026-10-08 安装
签名 Gatekeeper accepted、Notarized Developer ID，主体 Hangzhou Bobo Technology Co Ltd（网易关联主体，不是「网易」字样）

数据目录 ~/Library/Application Support/com.netease.uuremote/ 下有 Clipboard、Logs、MMKVRootDir、UploadLog、Download、Device_AppShortcut_Data 等子目录，最早痕迹可追到 3 月

两个观察：daemon + server 是开机常驻的，被控能力不是「用时才起」；以及客户端体积 185 MB，比上一期 RustDesk 的 69 MB 大近两倍——它是带完整串流与账号体系的产品，不是轻量工具。另外各端版本号并不同步（本机 Mac 版 4.42.0，Windows 端第三方站点已出现更新的版本号），查版本以官网下载页为准，别拿下载站数字当事实。

边界与注意

这一节比功能表重要。《软件许可及服务协议》（uuyc.163.com/contact/20240402/40294_1146065.html）逐条看：

  • 第 5 条：网易及关联方保留对增值服务收费、改变收费标准与方式的权利；免费变更为收费会通知，用户可选择接受或拒绝。「永久免费」是社区说法，不是协议条款。
  • 第 6 条：保留在服务中或通过服务投放广告和宣传信息的权利。
  • 第 2.1 条：授权范围是「单一一台终端设备上安装、使用一份副本」，并禁止复制、修改、挂接运行、创作衍生作品、使用非授权第三方工具接入。企业批量部署、二次集成、想接自己的自动化脚本，先确认授权——这条跟开源方案是根本区别。
  • 第 4.2 / 4.4 条：新版本发布后不保证旧版本继续可用；可经事先通知修改功能、中断或中止服务，且不承担由此产生的损失。工具链依赖它做长期无人值守，要留后手。
  • 第 3.3 条：被控方「分享本机并发送验证信息」即视为把系统权限授权给控制方，权限范围由双方自行确定。别把验证码随手发人。

《UU远程隐私政策》（.../40294_1146067.html）里，收集范围比很多人预期宽：

  • 使用「游戏云电脑」或其他需实名服务前，需填姓名和有效身份证件信息做实名认证；也支持网易邮箱/手机账号或第三方平台账号登录并获取授权信息。
  • 为运营安全收集的日志包括登录日志、操作信息、账号 ID、搜索查询内容、IP、运营商、网页浏览记录、停留时长等。
  • 设备信息里列到了设备标识符（MAC / IMEI / Android ID / IDFA / OpenUDID / GUID / SIM 序列号 / IMSI / OAID / 设备序列号）、Wi-Fi SSID、路由器 MAC(BSSID)、路由器机型与名称、主板厂商、CPU/GPU/内存使用情况、IP 与子网掩码等。

再叠上实测到的常驻 daemon 与剪贴板目录，结论很直接：「免费」的对价是账号、设备与网络侧的信息，以及一份可随时调整的服务条款。这不代表它不安全——官网列了端到端加密和三项认证——但它是闭源的，你没法像审 RustDesk 那样自己看代码、也没法把中继搬到自己机房验证。信任只能建立在厂商信誉和认证上。

其他要注意的：

  • 宣传数字看口径。「4K / 144 帧 / 500 Mbps」都是最高支持，实际取决于网络、被控端性能和编码；官方与第三方软文里的「18–30ms」「1ms 局域网」都没有可复核的测试条件，别当 SLA。
  • 云电脑是另一项服务，涉及实名与可能的付费，和「远控你自己的电脑」不是一回事，别混着算「全免费」。
  • 不用时关掉被控入口。官网提供「一键禁止远程协助」，长期不用的机器建议关掉，别让开机常驻的 daemon 白挂着。
  • macOS 权限要自己收。辅助功能、屏幕录制这类权限给了就是给了，卸载时顺手检查一遍系统设置。
  • 企业/合规场景先读协议。客户机器、内网资产走第三方账号体系与专网，通常不是技术问题是合规问题。

不适合谁：数据必须不出自己基础设施的团队（直接看上一期 RustDesk，或 MeshCentral）；需要审计客户端行为、二次开发、接入自己自动化系统的（协议 2.1 明确禁止）；把「永久免费」写进长期方案、无法承受服务条款变更的；以及对设备信息收集范围敏感、不愿用实名账号绑定远程控制权限的。

四期连起来看，其实是同一道选择题的四个答案：Pinky 把闸门装在审批网关，ego lite 装在标签页隔离，RustDesk 装在服务器归属，UU远程 装在厂商的服务条款里。前三个你都得自己动手，最后一个你几乎不用动手——它不是免费的午餐，是把运维成本和信任成本一起打包交了出去。想清楚自己更在意哪一头，选型就不纠结了。
