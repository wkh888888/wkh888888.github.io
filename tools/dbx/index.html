DBX：20MB 装下 90 种数据库的开源客户端

不用装 JRE、不用按数据库买授权，一个 20MB 的安装包把 MySQL 到 Redis 到国产库都收进去 —— 还顺手给 agent 开了个 MCP 口子。

它是什么

DBX（官网 dbxio.com，仓库 t8y2/dbx，18.1k+ star，完全开源）是一个跨平台的数据库客户端。体积约 20MB，支持 90+ 种数据库引擎：MySQL、PostgreSQL、SQLite、SQL Server、Oracle 这些常规项之外，Redis、MongoDB、Elasticsearch、ClickHouse、DuckDB 这类非关系型也包了，达梦、人大金仓、高斯、OceanBase、TiDB、PolarDB 等国产库是原生支持。

它最直接的对比对象是 DBeaver 和 Navicat：

维度 DBX DBeaver Navicat
体积 ~20MB 数百 MB 较大
运行时依赖 无 需 JRE 无
数据库支持 90+ 80+（国产库多要自己配 JDBC） 有限
Redis / Mongo 专用浏览器 支持有限 常需单独购买
AI 助手 内置 + MCP Server 无 无
价格 免费开源 免费 / 付费版 年费订阅

日常用起来是什么手感

写 SQL：CodeMirror 6 编辑器，补全带元数据（列名、表别名自动带出来），支持格式化、查询历史、选中部分 SQL 单独执行 —— 不用为了跑片段再复制一遍。

看数据：虚拟滚动的数据网格，大表翻页不卡；行内编辑、WHERE / ORDER BY 可视化控制、SQL 预览、导出（CSV / Excel / SQL inserts）都在手边。

看结构：侧边栏直接浏览库 / Schema / 表 / 字段 / 索引 / 外键 / 触发器，ER 图可视化表关系。

对比与迁移：Schema diff、表导入、数据库导出、SQL 文件执行、跨引擎数据传输。做环境对齐或换库时这类功能省的时间最多。

一个容易被忽略的亮点：MCP Server

DBX 自带一个 Rust 原生实现的 MCP Server。配到 Claude Code、Cursor 这类 agent 里之后，agent 能直接读数据库上下文、执行 SQL、打开表结构，不用你手动复制 DDL 和字段名喂给它。

权限分三级：read_only / safe_write / high_risk_write，可以精细控制 AI 能碰什么数据 —— 这条我认为是区分「玩具」和「能用在生产」的分界线。对现在满地跑 agent 的工作流来说，这个口子比 AI 生成 SQL 本身更值钱。

谁适合换过去

适合：

  • 同时连好几种数据库（尤其是混合了关系型 + Redis/Mongo + 国产库）；
  • 嫌 DBeaver 启动慢、要配 JVM 和 JDBC；
  • 想让 coding agent 直接访问数据库上下文；
  • 需要轻量、能 Docker 自托管的团队方案（它有桌面和 Docker 两种模式）。

不必换：

  • 只连一种数据库、且官方工具已经够用；
  • 需要非常深度的数据库专有能力（如 PL/SQL 调试、厂商特化管理功能），这类还是官方工具或付费软件更全；
  • 已在 Navicat 上买了多年授权且用得顺手。

上手

官网直接下对应平台安装包（macOS 分 Apple Silicon / Intel，Linux 有 x64 / ARM64，Windows 有常规与内网离线包）。装好建第一个连接，先试两个动作：一次跨引擎的数据导出，一次把 MCP Server 接到你常用的 agent 上 —— 这两件事最能说明它和传统客户端的区别。
