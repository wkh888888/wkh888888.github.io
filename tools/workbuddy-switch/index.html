WorkBuddy-Switch：给 WorkBuddy / CodeBuddy 装一个「换号总闸」

它不管你写不写代码，只管一件事——让你在多个 WorkBuddy / CodeBuddy 账号之间一键换号。

先说清楚它不是什么

第一次听说 WorkBuddy-Switch，容易和几个东西搞混，先划清边界：

  • 它不是 WorkBuddy 官方出品。是社区开源项目（作者 changexbc，MIT 协议，Rust + Tauri 构建，写这篇时最新 v0.1.58，GitHub 1055 ⭐ / 129 fork，更新很勤）。
  • 它也不是 CC Switch。CC Switch 管的是 Claude Code / Codex / Gemini 那一票 AI 编程工具的供应商配置切换；WorkBuddy-Switch 管的是 WorkBuddy / CodeBuddy 的账号登录态切换——两者对象完全不同，别混。
  • 它本身不调模型、不写代码。它只动「你以哪个账号登录」这件事。

所以预期摆正：装了它不会多出模型能力，它只是让你多账号之间切得爽一点、还能盯着积分别过期。

不想先装？官方有在线演示（只读，账号与积分均为虚构数据），可以先点开看一眼再决定。

它解决什么痛点

如果你只有一个 WorkBuddy 账号、从不换号，可以直接划走，你不需要它。

但只要符合下面任意一条，它就值：

  • 你有多个 WorkBuddy / CodeBuddy 账号（比如个人号 + 公司号，或国内版 + 国际版），每次换号都要退出重登、重新扫码；
  • 积分快过期了才发现、白白浪费，想提前看到期提醒；
  • 想看 Token 用了多少、哪个账号烧得凶；
  • 想把 A 账号里的某段会话挪到 B 账号接着干，又不想丢原数据。

核心功能（README 实锤，非营销稿）

模块 说明
账号管理 OAuth 扫码登录、导入导出账号（备份为 JSON）、删除账号、给账号加备注
账号切换 一键切换 WorkBuddy 登录账号，实时显示进度；国内版 / 国际版都支持
会话复制 把当前账号勾选的会话以新 id 复制给目标账号，源账号数据不受影响，云端归属目标账号
关联会话 复制过的会话自动建立跨账号关联；按客户端集中查看副本状态，支持增量同步、分歧处理、新增/解除关联，还有会话关联图
积分到期查询 自动查每账号积分剩余与到期时间，7 天内到期高亮，按紧迫程度排序并标注「建议优先使用」
积分统计 官方请求用量：总览、近 30 天趋势、模型分类、账号消耗与请求明细
Token 统计 按来源的总览与趋势，构成占比、活跃热力图、项目/模型 Top 10、会话排行
自动轮换 后台把积分最紧迫的账号设为 CodeBuddy CLI 后续启动账号；检测到 CLI 会话在跑就跳过
自动更新 从 GitHub Releases 检查新版，整包更新经签名校验
Agent Companion 悬浮窗 桌面悬浮栏集中显示 Codex / WorkBuddy / CodeBuddy / Codeg 会话的运行中/待确认/已完成状态，悬停查看详情，点击跳回原会话，托盘可隐藏
权限检测 macOS 授权引导（App 管理 / 完全磁盘访问 + 自动检测）

覆盖五个端：WorkBuddy、CodeBuddy IDE、CodeBuddy CLI、VS Code CodeBuddy 插件、JetBrains 插件（IDEA / PyCharm）。设置里可按客户端逐个开关入口（JetBrains 端默认关闭）。账号切换五端都支持；会话复制在 CLI 与 JetBrains 端不支持。

我认为最值钱的是两个：一键换号（把「退出重登扫码」变成一次点击）和 会话复制/关联（跨账号搬会话还不丢原数据，还能增量同步和处理分歧）。自动轮换属于「让积分自己先烧掉最紧迫的那个」的小聪明，挺实用。

平台与安装

原生桌面应用，Tauri 构建，三平台都有包：

平台 安装包
macOS Apple Silicon (arm64) workbuddy-switch_<版本>_aarch64.dmg
macOS Intel (x86_64) workbuddy-switch_<版本>_x86_64.dmg
Windows x64 workbuddy-switch_<版本>_x64-setup.exe
Linux x64 ..._amd64.deb / ..._amd64.AppImage

macOS 安装：打开 DMG，把 workbuddy-switch.app 拖入「应用程序」。首次启动若提示无法验证开发者，按住 Control 点击应用选「打开」，或去「系统设置 → 隐私与安全性」选「仍要打开」；仍报「已损坏」再跑一句 xattr -rd com.apple.quarantine "/Applications/workbuddy-switch.app"。

不想装桌面端还有 npm/webui 版（功能覆盖全部模块，但不含悬浮窗）：

npm i -g workbuddy-switch
workbuddy-switch          # 启动本地服务 + 自动开浏览器
workbuddy-switch status   # 终端看当前账号

本机已装：v0.1.58（macOS arm64 dmg），位于 /Applications/workbuddy-switch.app，quarantine 已清，Launchpad 可直接打开。

macOS 权限这道坎（别跳过）

切换账号本质是写入 WorkBuddy 认证文件，macOS 会拦。第一次切换报「无权限」时：

  1. 点「打开系统设置」；
  2. 优先在 App 管理里打开 workbuddy-switch 开关；没有的话去 完全磁盘访问把它拖进带箭头的框；
  3. 授权后要重启本应用才生效，设置页「权限检测」可随时验证。

不授权的话，应用能开、界面能看，但就是切不了号——这是最容易卡住的一步。

边界与注意

  • 它碰你的账号凭证。换号本质是读写 WorkBuddy / CodeBuddy 的本地登录态与会话，等于把钥匙交给了这个第三方开源应用——授权前想清楚，只用你信得过的版本、只从官方 Release 下。
  • 会话复制有数据流向。复制过去的会话云端归属目标账号，不是源账号的副本；敏感会话别随手往别的号搬。
  • 切 CodeBuddy CLI 会中断当前会话：它会先关掉正在运行的 CLI，当前会话直接中断且不会自动重开。其余各端（含 VS Code / JetBrains 插件）都能在客户端运行时自动完成切换。
  • 社区项目，非官方。WorkBuddy / CodeBuddy 的登录态格式一变，得等它跟进；好在更新勤，还有自动更新校验签名。
  • macOS 没公证是常态，那道 Gatekeeper 提示按上面方法处理即可，不是软件坏了。

适合谁

  • 手握多个 WorkBuddy / CodeBuddy 账号、经常换号的人——这是它的主场；
  • 怕积分过期、想盯着 Token 用量的人；
  • 需要在账号间搬会话、又不想丢原数据的人；
  • 同时用 VS Code 和 JetBrains（IDEA / PyCharm）的 CodeBuddy 插件、懒得分别处理的人。

只有一个账号、从不在多账号之间切的，不用装，少一个常驻应用。
