ToDesk：免费版止步 1080P/30 帧，剩下的明码标价

连着三期远控，RustDesk 把服务器交给你、UU远程把成本藏进协议、ToDesk 干脆给每一帧标上价——选型其实是在挑你愿意承担哪一种不确定性。

先说清楚它不是什么

写到第五期，远程桌面这条线正好凑齐了四种活法。ToDesk 是其中把商业规则写得最直白的那个，但也最容易被「免费下载」四个字误读：

  • 它不是开源或可自建的中间层。闭源商业软件，没有公开服务端；账号、节点、设备列表都在厂商侧。（想要中间层自己跑，回第 13 期 RustDesk。）
  • 它的「免费」不是全功能，是明确受限的一档。官方定价页写得清清楚楚：个人版最高 1080P、30 帧、4Mbps 带宽、3 个分组、1 个通道、同时控制 2 台。这不是藏起来的限制，是印在价目表第一行。
  • 它不是「公司电脑也能随便装」。这是本期最该先说的一条：《ToDesk 用户协议》第 1 条明确，个人版（含主控端、被控端、精简版）仅供个人所有的设备、非商业用途使用；只要用于商业目的（对第三方收费、项目投标、后台管理系统、任何直接或间接获取收益），或装在法人/组织所有的设备上，就不在个人版合法授权内，须购买性能版 / 团队版 / 企业版。很多人是在公司电脑上装免费版的，这条建议先读完再决定。
  • 它不是只有一个付费档。个人侧拆成专业 / 游戏 / 设计 / 性能四档，外加一堆按月加购的插件，还有企业版与私有化部署方案——它是一整个产品矩阵，不是「免费 + 会员」两级。
  • 它不是只给办公用的。游戏键鼠手柄、4:4:4 真彩、数位板映射、8K/360 帧分别落在不同档位，设计、剪辑、游戏场景是分开定价的。
  • 官网首页那些 8K / 360 帧 / 3ms 不是免费版能力，是性能版与企业版的宣传口径，且都标着「最高支持」。

预期摆正：ToDesk 卖的是可预期的性能和一套企业管理能力。它不跟你谈数据主权，也不跟你谈「永久免费」。

数据来源说明：闭源产品，无 GitHub 仓库。一手材料是官方定价页 todesk.com/pricing.html、《ToDesk 用户协议》（生效日期 2026-05-13）、《ToDesk 隐私政策》、官网产品页，加上本机 App 实测，均为 2026-11-11 拉取。官网不同页面间数字略有出入（用户数有「2.8 亿+」与「3 亿+」两种写法、旧版对比页档位少一档），本文一律以当前定价页 ?pt=1 为准；宣传性的延迟/画质数字一律标「官方口径」。

它解决什么痛点

  • 国内跨网远控要稳：普通免费节点走 SD-WAN，付费档换 RTC + VIP 专属节点；对「异地连公司电脑、别掉线」这种刚需，节点质量是能花钱买到的。
  • 设备多了要管：设备列表 100→300 台、分组数、通道数、同时控制会话数、屏幕墙，全是按档位解锁的管理能力，个人用户和代维团队的需求差得很远。
  • 企业要批量部署和审计：命令行静默部署上万台、对接 AD 域 / 飞书 / 企微账号、云端加密录屏、安全日志、可控文件传输、私有化部署方案——这些是 UU远程那类个人免费工具不提供的。
  • 专业场景要确定性：设计要 4:4:4 真彩和数位板映射，游戏要 240 帧和手柄，运维要远程终端和多开会话。分档虽然烦，但至少你要什么、花多少钱，是一张表能查清的。

这一点我想多说一句：上一期 UU远程把核心功能全标免费，代价写在协议第 5 条「保留转收费」里；ToDesk 反过来，把每一档的分辨率、帧率、带宽、设备数、价格全部列出来。对企业选型，「明码标价」本身就是一种确定性——预算、合规、三年后的成本都能算，不用赌厂商哪天改策略。

我认为最值钱的两个：带宽和帧率被写进价目表（4Mbps/30 帧 vs 60Mbps/360 帧，差异是可预期的，不是「晚上卡不卡看运气」）和企业版的批量部署 + 审计闭环（这是个人免费工具与商业远控真正的分水岭）。反过来说，这张表也是它最劝退的地方——档位多、插件多，选错档就得再加钱。

平台与安装

官网下载各端客户端，注册账号后设备列表云同步；临时协助可用精简版 / SOS 绿色被控端，对方不必完整安装。企业侧支持命令行静默部署与账号批量导入。

边界与注意

  • 最硬的一条：免费个人版不得用于商业用途或公司设备。用户协议第 1 条把「项目投标、后台管理系统、任何直接或间接获取收益」和「法人/组织所有的设备」都排除在外，并要求购买性能版 / 团队版 / 企业版取得商用授权，否则保留追责与终止服务的权利。办公室里那台装了免费版的电脑，值得先确认一下授权。
  • 免费档的 4Mbps / 30 帧是真实体感分界线。看文档、改文件够用；传大素材、多屏、高刷、看设计稿色差就会明显不够——这正是分档设计的目的，别把它理解成「限速惩罚」。
  • 总成本要连插件一起算。通道数默认全是 1，多主控同时发起要加购「多通道」¥233/月；跨境要「全球节点」¥66/月；这些都不在档位标价里。
  • 协议里的服务不确定性：第 5 条可因商业决策中止/中断/终止服务、公告通知但不承担损失；7.4 条责任上限不超过已支付费用；7.5 条可能实时更新软件，未更新不保证正常使用。跟上一期 UU远程的条款属于同一类商业软件常态，做长期无人值守要留备用通道。
  • 账号与实名：隐私政策写明注册需手机号，部分服务/场景按法规要求需实名认证（身份证信息加密送权威机构核验，必要时可能涉及人脸图像/视频，官方称不保存）。企业账号体系要提前跟合规对齐。
  • 凭证别当强认证。GitHub 上存在能从进程内存读取远控设备码 / 连接密码的公开工具（同类工具也针对其他远控软件），这说明固定密码与无人值守不应被视为强认证——前提是本机已经失陷，不是传输层被攻破。建议开新设备验证、动态口令 / 二次验证、一次性临时密码、「仅接受请求」，并让会话结束自动锁屏。
  • 闭源不可审计。端到端加密是官方声明，可对照的只有官网列的安全措施与企业版审计功能；不能像 RustDesk 那样自己看代码或把中继搬回机房。
  • 宣传数字看口径。8K / 360 帧 / <3ms 都标「最高支持 / 官方口径」，且定价页自己注明「需主被控都支持最高分辨率」，还受带宽上限约束；官网不同页面的用户规模数字也不完全一致。
  • 组件会驻留系统。服务进程 + 音频驱动 + 系统权限，长期不用的机器建议关掉「允许远程控制」，卸载后检查系统设置里的辅助功能、屏幕录制、音频设备。

  • 要在公司环境里正经用远控的人：付费档换取商用授权，企业版换批量部署与审计，这是它比「免费工具」更合适的地方；

  • 代维 / IT 运维：设备列表、分组、屏幕墙、多通道、远程终端，管理多台机器时比单点连接重要；

不适合谁：只是个人偶尔连一次家里电脑的（免费档够用，但 4Mbps 别指望传大文件；更不在乎的话 UU远程更爽）；数据必须完全不出自己基础设施且拒绝商业授权的（回 RustDesk）；讨厌档位 + 插件叠加、只想一个价拿到全部的；以及正在公司电脑上用免费个人版却没读过协议第 1 条的——这条最该先处理。

五期连起来看，其实是同一道选择题的五个答案：Pinky 把闸门装在审批网关、ego lite 装在标签页隔离、RustDesk 装在服务器归属、UU远程 装在厂商的服务条款、ToDesk 装在一份价目表与商用授权里。前三个要你动手，后两个要你付钱或交出信任。没有哪条路绝对更好——先想清楚你更怕的是麻烦、是失控，还是明年突然涨价，选型就不纠结了。
