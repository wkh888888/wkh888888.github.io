ima.copilot：腾讯的「会思考的知识库」，把收藏吃进肚子里

普通网盘只会「存」，ima 会「想」——你收藏的每一份资料，它读得懂、找得到、用得上。

先说清楚它不是什么

第一次听说 ima，容易和几个东西搞混，先划清边界：

  • 它不是又一个聊天机器人套壳。ima.copilot（下称 ima）是腾讯 2024 年推出的 AI 工作台，2025 年 10 月发布 2.0，核心是以知识库为底座：先把你的资料收进来、解析好，再让模型基于这些资料回答和创作。
  • 它不是网盘。存文件只是第一步，解析、检索、问答、生成才是重点；原文链接失效后，已入库的解析内容照样能搜能问。
  • 它不是 WeKnora。WeKnora 是腾讯把 ima 知识库能力开源后的私有化部署方案（LLM + RAG，Docker 部署），面向数据隐私要求高的组织；ima 是线上托管版，数据在腾讯云。两者选一个，别纠结。
  • 它不接你自己的 API Key。模型固定用腾讯混元 + DeepSeek R1 满血版，不能换成别的供应商——要自由选模型，那是 CC Switch 那类工具的活。

预期摆正：ima 适合「资料多且散、想沉淀成个人第二大脑」的人；想要完全私有部署的，出门右转 WeKnora。

它解决什么痛点

符合下面任意一条，它就值：

  • 微信里收藏了几百篇文章从来没再看过，想用的时候找不到；
  • PDF / 论文 / 财报存了一堆，每次要靠手动翻；
  • 团队资料散在每个人手里，新人问事全靠口口相传；
  • 用通用 AI 问自己行业的问题，答案永远隔着一层——因为它不认识你的资料。

ima 的打法是：搜 → 读 → 写闭环。资料从微信、网页、本地文件一键入库，AI 基于库内内容精准问答（带出处），需要产出时直接调用库内知识生成文章、报告、脑图、播客。

核心功能

模块 说明

SkillHub 技能生态，可安装技能扩展工作台能力

容量：官方口径免费 30GB 起步、成长体系可扩（社区文章有称 50GB，以客户端「头像 → 存储空间」实际显示为准）；发布到知识库广场的共享库不占个人空间。

我认为最值钱的两个：微信生态一键收录（把「收藏吃灰」变成「入库可问」）和带出处的库内问答（答案是拿你自己的资料回答的，不是模型瞎编）。团队共享库对「资料在个人手里」的团队是刚需。

macOS 安装：下载 universal dmg（当前 ima.copilot_universal_1018_2.6.9_5083.dmg，约 354MB，直链 https://app-dl.ima.qq.com/app/），拖入「应用程序」即可。

本机已装：150.0.7871.5272（2026-10-12 由 147.0.7727.4985 更新），位于 /Applications/ima.copilot.app。

macOS 更新这道坎（2026-09 官方已确认）

Mac 版 2026 年 9 月出过一次更新后启动闪退，官方频道的处置方案值得记一下：

  1. 官方先让受影响用户回退指定版本（即上面那个 2.6.9_5083），并关掉自动升级；
  2. 根因解法是：系统设置 → 语言与地区 → 地区改成「中国大陆」，之后即可正常更新（后续 2.6.10 有用户确认修复）。

我这次更新走的是手动下 universal dmg 覆盖安装，没触发应用内升级通道，也就没踩这个坑。建议 Mac 用户先确认系统地区为中国大陆，再决定要不要开自动更新。

边界与注意

  • 数据在腾讯云。知识库内容、笔记、录音全部托管在腾讯服务器，公司机密、个人敏感资料想清楚再入库；不能接受的用开源 WeKnora 私有化部署。
  • 模型锁死。只有混元 + DeepSeek R1，不能接自己的 Key，也不能用别的模型——这是它和通用 AI 客户端的本质区别。
  • 发布到广场 = 公开。共享知识库一旦发布到知识库广场就是公域内容，加入超 500 人还会解锁数据看板；发布前想清楚。
  • 免费是现状不是承诺。核心功能目前免费，存储成长体系规则以后可能变，重度使用者留个后手（本地保留原件）。
  • 解析质量看格式。扫描版 PDF、复杂排版表格的解析效果会打折扣，OCR 入口就是为这个准备的，但别期望 100%。

适合谁

  • 分析师 / 研究员：行业资料、会议录音、调研报告入库，出报告时基于自己的资料问；
  • 学生 / 教师：课件、论文、板书拍照入库，生成要点、脑图、播客；
  • 律师 / 金融 / 政务等垂直从业者：订阅广场上的垂直知识库，比通用搜索精准；
  • 小团队：共享知识库 + 权限分级，把「资料在个人手里」变成「团队资产」。

只有一两份文档、从不积累资料的人不用装；数据必须完全私有、不能上云的，直接看 WeKnora。
